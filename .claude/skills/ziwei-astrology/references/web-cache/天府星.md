# 天府星核心断语

> 搜索时间: 2026-05-22
> 来源: ziwei-doushu本地仓库

## 基本特质

天府为南帝守财星，主稳重保守，化气为令。落命主品行端正、善守财库。

- 关键词：财库·稳重·保守
- 星性：吉星
- 五行：土
- 亮度：仓库中暂无天府完整亮度表（天府亮度系统与紫微联动）

## 十二宫断语

**命宫**：天府入命，品行端正，稳重保守，善守财库。紫微天府同入命宫（限寅、申宫），帝相并临，尊贵之命，主品行端正、衣食无忧、有领导才能，宜担任要职。需要左右辅弼来配合方为完整大格。

**夫妻宫**：善曜，主生离不死别，感情平稳但平淡。见禄存或化禄：财禄双全，感情稳定；三方无煞：夫妻平静和谐。辅弼单星：易有第二次婚姻；遇四煞：感情漠然，生离概率增加。配偶温文尔雅，兴趣广泛，守财有原则，工作能力强，但偏保守。男命配偶年长，女命配偶年少；感情稳定但需主动经营。

**官禄宫**：天府入官禄，宜财务管理、银行、行政管理，稳重保守但根基扎实。

**财帛宫**：天府为财库星，入财帛宫善守财，见禄存则财库丰盈。

**田宅宫**：天府入田宅，房产运佳，居家安稳，善置产。

## 四化影响

天府不参与四化。

天府为南帝星，本身不化禄权科忌，其吉凶完全取决于三方四正的会照星曜。见禄存或化禄则财库丰盈，见煞星则财库有漏。天府最喜与禄存同宫或会照，形成"府库充盈"之象；最忌空库——三方无禄又见空劫，反主虚有其表。
