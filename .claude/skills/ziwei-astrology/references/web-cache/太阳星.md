# 太阳星核心断语

> 搜索时间: 2026-05-22
> 来源: ziwei-doushu本地仓库

## 基本特质

太阳为男贵星，主名誉公务，化气为贵。落命主光明磊落、宜公职名声。

- 关键词：阳刚·官贵·慷慨
- 星性：吉星
- 五行：火
- 亮度：卯辰巳午庙旺，未申酉平，戌亥子丑陷。太阳亮度极度依赖宫位——白天（卯至申）庙旺，夜晚（酉至寅）落陷。

## 十二宫断语

**命宫**：太阳入命，光明磊落，慷慨大方，有公众形象意识。庙旺时男命主贵，女命旺夫；落陷则虚耗精神，男命劳碌，女命刑克。

**夫妻宫**：男命助妻，女命旺夫；落陷化忌则反主刑克。庙旺（卯至申宫）：配偶能干，男命有贤内助；女命嫁旺夫，婚姻美满。落陷（酉至寅宫）：男命配偶病弱，女命嫁庸夫。配偶开朗大方，有公众形象意识，慷慨但有时过于强势。感情走势始热终冷，宜保持适当距离维持新鲜感。

**官禄宫**：太阳入官禄，宜公职、政治、教育、公益，庙旺主官贵。

**财帛宫**：太阳主贵不主富，但庙旺时因名得财，落陷则财来财去。

**迁移宫**：太阳在迁移，出外有名，庙旺宜远行发展，落陷则在外劳碌。

**福德宫**：太阳在福德，精神世界光明积极，落陷则内心空虚。

## 倪师天纪断语

1. 天纪DVD03："太阳星庙旺利陷"——太阳亮度对命运影响极大
2. 夫妻宫断语："太阳化忌，上不见父，下不见子，中不见夫——女命那十年丈夫必有重大灾祸"
3. 阳梁昌禄格：太阳、天梁、文昌、禄存四星齐会命宫三方，号称"科举之星"，主清贵显达
4. 日月同宫：太阳太阴于丑/未宫同宫，阴阳平衡，文武兼备
5. 日月夹命：太阳太阴分居命宫两侧夹照，光明磊落，一生贵人相助

## 四化影响

太阳参与三化：

- **庚干化禄**：太阳化禄，光明生财，因名得利，宜公职、公众事业
- **辛干化权**：太阳化权，光明得权，掌控力增强，宜领导岗位
- **甲干化忌**：太阳化忌，光明受损，名誉受挫，男命自身事业受阻，女命"上不见父，下不见子，中不见夫"——那十年丈夫有重大灾难

太阳化忌是倪师反复强调的重大凶象，尤其女命太阳化忌落陷，需特别关注父亲、丈夫、儿子的健康与安全。
