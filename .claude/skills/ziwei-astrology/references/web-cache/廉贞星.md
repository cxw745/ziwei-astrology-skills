# 廉贞星核心断语

> 搜索时间: 2026-05-22
> 来源: ziwei-doushu本地仓库

## 基本特质

廉贞为次桃花星，文武兼备，化气为囚。落命主多才多艺、感情丰富。

- 关键词：才艺·刑囚·桃花
- 星性：凶中带吉
- 五行：火
- 亮度：寅申丑未庙旺，子卯午酉平，辰戌巳亥陷

## 十二宫断语

**命宫**：廉贞入命，多才多艺，感情丰富，文武兼备。廉贞天相同宫，印绶格局，主秉公处事、清廉之名，宜任公职、行政管理、法务、企划。怕见擎羊化忌，则反主官非。

**夫妻宫**：夫妻宫最不稳定的主星，生离死别风险高。廉贞天府（子午）：配偶温和清秀，感情尚可，配偶多为薪水族。廉贞贪狼：非生离即死别；廉贞破军：水中做坟墓；廉贞七杀：半路埋尸体；化忌：感情骚扰不断，和好破裂循环；与火星同宫：纵有吉曜也分居。配偶外形出众，善于交际，情绪价值高，但不稳定；可能离多聚少。男命宜配年少之妻（年轻6-12岁），女命宜配年长之夫。

**官禄宫**：廉贞入官禄，宜公职、法务、行政管理，化禄时清廉得财，化忌时官非缠身。

**财帛宫**：廉贞主才艺不主正财，见禄存或化禄方可稳定。

**疾厄宫**：廉贞属火主心，入疾厄需防心脏、血液循环疾病，化忌时尤甚。

## 倪师天纪断语

1. 天纪DVD04："廉贞囚星"——廉贞化气为囚，主刑囚桃花
2. 夫妻宫断语："廉贞贪狼/廉贞破军在夫妻宫，不管男命女命，非生离即死别；廉贞七杀——半路埋尸；廉贞破军——水中做冢；廉贞贪狼——横夭（夭折）"
3. 廉杀羊格：廉贞、七杀、擎羊三星会照命宫三方，古书警示之凶格，主血光、官非、意外
4. 廉贞天相格：廉贞天相同宫，印绶格局，主秉公处事、清廉之名

## 四化影响

廉贞参与两化：

- **甲干化禄**：廉贞化禄，囚星得禄，才艺生财，感情顺遂，宜公职、文艺、管理
- **丙干化忌**：廉贞化忌，囚星化忌，感情骚扰不断，官非缠身，和好破裂循环

廉贞化忌是倪师反复警示的凶象，尤其在夫妻宫，感情反复破裂，难以善终。廉贞化忌遇火星同宫，纵有吉曜也分居。
