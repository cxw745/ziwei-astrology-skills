# 网页搜索缓存目录

> 此目录用于缓存网页搜索补充的知识内容，避免重复搜索。

## 格式规范

每个缓存文件命名格式：`{主题关键词}.md`

文件内容格式：
```markdown
# {关键词}

> 搜索时间: {YYYY-MM-DD}
> 来源: {URL}
> 可信度: {古籍原文/学术论文/专业论坛/个人博客}

{搜索到的内容}

---
冲突标注：{如与仓库内容冲突，在此说明，以仓库为准}
```

## 使用规则

1. 搜索前先检查本目录是否已有相关缓存
2. 新搜索结果保存到本目录
3. 缓存内容与仓库冲突时以仓库为准
4. 引用缓存内容标注 `[来源: 网络搜索-缓存]`
