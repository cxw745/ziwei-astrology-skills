# 武曲化忌

## 武曲星性总论

武曲为财星，五行属金，主刚毅、决断、理财。庙旺时理财有方、果决进取；化忌时则刚愎自用、固执孤克，财路受阻。武曲化忌由壬干引发，是倪师体系中极为重要的凶象之一。

## 武曲化忌在各宫位影响

**命宫武曲化忌**：性格过于刚硬，不通人情，与人相处困难。做事固执己见，听不进劝，容易因执念而错失良机。倪师断语："武曲化忌坐命，为人孤克，六亲缘薄。"

**夫妻宫武曲化忌**：婚姻最大凶象之一。武曲本为寡宿星，化忌则刑克更重。倪师原话："武曲化忌，为刑囚之星，武曲系婚姻宜晚。"早婚必离，30岁后婚配方可化解部分凶性。配偶性格刚硬，夫妻争执不断。

**疾厄宫武曲化忌**：呼吸系统、肺部疾病风险极高。武曲属金主肺，化忌则金气受损，需防肺病、支气管炎、骨骼关节问题。倪师结合中医："武曲化忌在疾厄，肺部呼吸系统要特别注意。"

**财帛宫武曲化忌**：财星化忌入财帛，看似矛盾实则大凶——理财能力反而受阻，投资失利，钱财被劫。不宜投机，宜稳扎稳打。

**官禄宫武曲化忌**：事业中刚愎自用，与上司同事冲突频繁，升迁受阻。适合独立创业但需防合伙纠纷。

**田宅宫武曲化忌**：房产交易易出问题，买卖房屋需谨慎，不宜炒房。

## 倪师核心观点

1. 武曲化忌是"刑囚"之象，不论落在何宫皆主"孤"——孤于亲、孤于财、孤于情
2. 武曲化忌在夫妻宫，倪师一律建议晚婚，30岁前结婚几乎必离
3. 武曲化忌遇煞星齐聚，需防重大财务损失或法律纠纷
4. 化解之道：晚婚、独立事业、避免合伙、理财保守
