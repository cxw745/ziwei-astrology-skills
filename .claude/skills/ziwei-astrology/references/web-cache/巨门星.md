# 巨门星核心断语

> 搜索时间: 2026-05-22
> 来源: ziwei-doushu本地仓库

## 基本特质

巨门为是非口才星，主辩论传媒，化气为暗。落命主口才好、宜律师教师。

- 关键词：口舌·是非·善辩
- 星性：凶中带吉
- 五行：水

## 十二宫断语

**命宫**：巨门入命，口才好、善辩、多思多虑。巨门坐命子午，为"石中隐玉"格——外表平凡而内蕴才学，早年默默无闻、中年方显贵气，宜走专业、研究、口才、传媒。需有禄权或文昌相助方能"凿石见玉"。

**夫妻宫**：口舌是非多，夫妻易争吵，需太阳化解。太阳庙旺相会：反主婚姻和美，口才化为沟通利器；化禄：妻子贤能，财路因妻而开。化忌：配偶爱唠叨，是非不断；陀罗同度：夫妻自寻烦恼；独守无吉：感情压抑，深层矛盾多。配偶口才好，嫉妒心强，在乎面子，有时过于挑剔，但内心深情。需做好长期沟通磨合的心理准备。

**官禄宫**：巨门入官禄，宜律师、教师、传媒、外语、专业咨询，口才为事业利器。

**财帛宫**：巨门主口才生财，化禄时财路因口才而开，化忌则因口舌破财。

**迁移宫**：巨门在迁移，出外多是非，但太阳庙旺相会则反主在外得名。

**交友宫**：巨门在交友宫（仆役宫），倪师断语："巨门在朋友宫，跟朋友合伙会朋友变仇人。"

## 倪师天纪断语

1. 天纪DVD04："巨门暗星"——巨门化气为暗，主是非口舌
2. 巨日同宫：巨门太阳同入寅/申宫，太阳化解巨门暗曜，主以口才、传媒、外语、专业立业。寅宫为佳，申宫力减
3. 石中隐玉格：巨门坐命子午，外表平凡而内蕴才学，需有禄权或文昌相助方能"凿石见玉"
4. 巨火羊格：巨门、火星、擎羊三星会照，古书云"巨火羊，终身缢死"——古时凶格，现代理解为易因口舌、激烈冲突而招大祸
5. 交友宫断语："巨门在朋友宫，跟朋友合伙会朋友变仇人"

## 四化影响

巨门参与三化：

- **辛干化禄**：巨门化禄，口才生财，是非化为财路，宜律师、传媒、咨询
- **癸干化权**：巨门化权，口才得权，辩论能力增强，宜法律、教学、专业权威
- **丁干化忌**：巨门化忌，口舌化忌，是非不断，官非缠身，配偶爱唠叨

巨门化忌时口舌是非最重，需特别注意言辞，避免官非。巨门化忌在夫妻宫，配偶唠叨不断，夫妻争吵频繁。
