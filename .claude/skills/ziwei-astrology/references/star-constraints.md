# 星曜联合判定约束

> 灵感来源：vedic-astro-skills 的 PAC 联合判定机制（Planet-Aspect-Combination），适配紫微斗数星曜体系重写。

## 核心理念

当一颗星同时受多个因素影响时（如主星庙旺但化忌同宫），**禁止取平均**，**禁止自创折衷表述**。必须按冲突仲裁规则给出明确结论。

## 信号分诊

分析前先做信号分诊，按星曜状态标记分析深度：

| 级别 | 条件 | 分析深度 |
|------|------|---------|
| A级 | 庙旺+化禄/化权/化科 / 落陷+化忌 / 参与格局的星 / 煞星同宫 | 3-4段深度分析 |
| B级 | 平+辅星会照 / 单独坐宫无煞 | 2-3段标准分析 |
| C级 | 无特殊状态 | 1-2段简要分析 |

验前事优先从A级信号推导。

## 冲突仲裁规则

当一颗星同时受正面和负面因素影响时，按以下4条规则仲裁：

### 规则1：主星庙旺 + 化忌同宫 = "带毒高价值"

```
含义：能力很强但用力的方向容易偏
表述："XX星庙旺，能力出众，但化忌同宫，执念深，越强越容易在XX领域钻牛角尖"
禁止："有好有坏""综合来看还行""虽然化忌但庙旺可以化解"
```

### 规则2：主星落陷 + 化禄同宫 = "表面风光底子虚"

```
含义：有收入/机会但不稳定
表述："XX星落陷，根基不牢，虽有化禄带来表面收益，但难以持久"
禁止："化禄可以弥补落陷""落陷但化禄也不错"
```

### 规则3：空宫 + 吉星会照 = "有贵人但自己弱"

```
含义：靠人不如靠己
表述："该宫无主星坐守，力量需借对宫/会照吉星，有贵人助力但自身稳定性不如实坐"
禁止："空宫反而灵活""空宫有吉星等于有主星"
```

### 规则4：多因素矛盾 = 标注"信号混合"

```
含义：无法用单一规则仲裁的复杂情况
表述："该宫位信号混合：{正面因素} vs {负面因素}，实际表现取决于大限/流年触发方向"
禁止：强行解释为单一方向
```

## 常见冲突场景速查

| 场景 | 仲裁规则 | 标准表述 |
|------|---------|---------|
| 紫微庙旺+化权 | 无冲突，A级正面 | "紫微庙旺化权，领导力强，有掌权之象" |
| 太阳庙旺+化忌 | 规则1 | "太阳庙旺化忌，光明磊落但执念于面子，越要面子越容易受伤" |
| 武曲落陷+化禄 | 规则2 | "武曲落陷化禄，有财来但守不住，赚多花多" |
| 命宫空宫+左辅右弼会照 | 规则3 | "命宫空宫得辅弼会照，有贵人但自身定力不足" |
| 天机平+擎羊同宫 | 无冲突，A级负面 | "天机平遇擎羊，思虑受阻，容易犹豫不决" |
| 廉贞庙旺+火星+化禄 | 规则4 | "信号混合：廉贞庙旺化禄（正面）vs 火星同宫（冲动），实际表现看大限触发方向" |
| 七杀+化权+落陷 | 规则1变体 | "七杀落陷化权，冲劲大但方向容易偏，越努力越可能走弯路" |
| 太阴庙旺+地空 | 规则4 | "信号混合：太阴庙旺（细腻富有）vs 地空（虚耗），财运有但留不住" |

## 禁止的折衷表述清单

以下表述**硬性禁止**使用：

| 禁止表述 | 原因 | 替代方案 |
|---------|------|---------|
| "有好有坏" | 取平均，无信息量 | 引用具体仲裁规则 |
| "综合来看还行" | 圆场，回避矛盾 | 列出正面和负面因素，标注信号混合 |
| "虽然X但Y可以化解" | 美化负面因素 | "X的影响客观存在，Y提供缓冲但不能化解" |
| "只要努力就能克服" | 鸡汤，无视客观条件 | "客观条件有压力，可通过XX方式缓解" |
| "这也是一种成长" | 灵性包装凶象 | "这是客观的压力信号" |
| "不必过于担心" | 讨好安慰 | 如实描述影响和应对策略 |
| "反而能成就更大" | 逆转凶象 | "压力下可能有突破，但压力本身是真实的" |

## 与宫位分级制的配合

宫位分级制（重点宫7子节/普通宫5子节/轻量宫3子节）决定**展开篇幅**，信号分诊决定**分析深度**。两者独立：

- 一颗落陷化忌的星在轻量宫 → 篇幅3子节，但每节深度按A级
- 一颗庙旺无煞的星在重点宫 → 篇幅7子节，但分析深度按B级
