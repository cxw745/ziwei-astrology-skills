# 时辰映射表

## 时辰索引与时间对应

| 索引 | 时辰 | 时间范围 |
|------|------|---------|
| 0 | 早子时 | 00:00~01:00 |
| 1 | 丑时 | 01:00~03:00 |
| 2 | 寅时 | 03:00~05:00 |
| 3 | 卯时 | 05:00~07:00 |
| 4 | 辰时 | 07:00~09:00 |
| 5 | 巳时 | 09:00~11:00 |
| 6 | 午时 | 11:00~13:00 |
| 7 | 未时 | 13:00~15:00 |
| 8 | 申时 | 15:00~17:00 |
| 9 | 酉时 | 17:00~19:00 |
| 10 | 戌时 | 19:00~21:00 |
| 11 | 亥时 | 21:00~23:00 |
| 12 | 晚子时 | 23:00~00:00 |

## 常见用户表达映射

- "凌晨1点" → 丑时(1)
- "早上8点" → 辰时(4)
- "中午12点" → 午时(6)
- "下午3点" → 申时(8)
- "晚上8点" → 戌时(10)
- "半夜12点" → 早子时(0)
- "半夜11点半" → 晚子时(12)

## 农历月份修正

若修正闰月（fixLeap=true），闰月15日（含）之前算当月，之后算下月。
iztro 的 bySolar 第四个参数 fixLeap 控制此行为，默认传 true。
