# 快捷指令详细指引

## 专项解读指令

### `\money` 财运详解
深入分析财帛宫+田宅宫+福德宫，含理财建议和财运周期。输出7章节：财帛宫详析、田宅宫详析、福德宫与财运、大限财运周期、流年财运提示、理财建议、总结评级。

### `\health` 健康详解
深入分析疾厄宫+来因宫，含先天体质和预防建议。输出7章节：疾厄宫详析、来因宫与健康、十二宫健康映射、大限健康周期、流年健康提示、预防建议、总结评级。

### `\love` 感情详解
深入分析夫妻宫+福德宫，含婚期判断和感情建议。输出8章节：夫妻宫详析、福德宫与感情、婚期判断三层法、桃花运势、大限感情周期、流年感情提示、感情建议、总结评级。

### `\career` 事业详解
深入分析官禄宫+财帛宫+命宫，含职业方向和事业周期。输出7章节：官禄宫详析、财帛宫与事业、命宫与事业格局、大限事业周期、流年事业提示、职业建议、总结评级。

### `\year` 流年运势
分析当年及未来3年运势，含关键月份和转折点。

## 时运选择指令

### `\dash` 大限选择

列出命盘中所有大限供用户选择：

```
📊 大限一览（{出生日期} {性别}）

第1大限  {年龄}岁~{年龄}岁  {宫名}（{天干地支}）  主星：{星耀}
第2大限  {年龄}岁~{年龄}岁  {宫名}（{天干地支}）  主星：{星耀}
...

👉 输入 `\dash N` 查看第N大限详解（如 `\dash 3`）
📌 当前所在大限：第{X}大限（{年龄}岁~{年龄}岁）
```

`\dash N` 直接查看第N大限详解。大限详解输出8章节：大限基本信息、大限命宫详析、大限四化（标注"iztro功能，倪师体系不使用"）、大限夫妻宫专题、大限官禄宫专题、大限财帛宫专题、大限关键流年、大限整体运势评级。

### `\flow` 流年选择

列出流年供用户选择，默认显示当前年龄前后10年：

```
📅 流年一览（{出生日期} {性别}，当前{年龄}岁）

{年份}（{干支}）{年龄}岁  流年宫位：{宫名}  四化：{化禄星}/{化权星}/{化科星}/{化忌星}
...

👉 输入 `\flow YYYY` 查看指定年份详解（如 `\flow 2026`）
📌 当前年份：{YYYY}年（{干支}年）
💡 输入 `\flow all` 查看完整流年列表（从出生到100岁）
```

`\flow YYYY` 直接查看指定年份详解。流年详解输出10章节：流年基本信息、流年四化详析、流年宫位与本命交互、流年与大限叠加、事业运势、财运运势、感情运势、健康运势、关键月份、流年吉凶评级。

### `\month` 流月选择

列出指定流年的12个月供选择：

```
📆 流月一览（{YYYY}年{干支}年）

1月（{干支}月）流月宫位：{宫名}  四化：{化禄星}/{化权星}/{化科星}/{化忌星}
...
12月（{干支}月）流月宫位：{宫名}  四化：{化禄星}/{化权星}/{化科星}/{化忌星}

👉 输入 `\month YYYY-MM` 查看指定月份详解（如 `\month 2026-05`）
📌 当前月份：{M}月
```

`\month YYYY-MM` 直接查看指定月份详解。流月详解输出10章节：流月基本信息、流月四化详析、三层叠加分析（流月+流年+大限+本命）、事业运势、财运运势、感情运势、健康运势、该月宜忌、关键日期、流月吉凶评级。

## 辅助指令

### `\question` 随机提问
从命盘中最有故事性的要点中选取提问，如格局的特殊组合、四化的交互影响、大限的关键转折等。

### `\switch` 切换体系
在iztro/倪师/综合三种解读模式间切换。`\switch 倪师`、`\switch iztro` 可直接指定。

### `\help` 帮助
显示所有可用快捷指令和使用说明。

## 使用规则

- 用户输入以 `\` 开头时识别为快捷指令，不区分大小写
- 首次排盘前使用快捷指令，先提示用户提供出生信息
- 所有快捷指令基于已排命盘数据，不重新排盘
