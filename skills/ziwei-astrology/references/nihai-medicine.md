## 二、十四主星疾厄宫断语（倪师中医视角）

以下断语不同于 [palace-interpretation.md](palace-interpretation.md#疾厄宫断语) 的简表，而是从倪师中医体系出发，将每颗主星在疾厄宫时的健康含义与倪师人纪课程中的脏腑病机、经方、针灸方案深度联动。

### 紫微（土·脾胃）

- **疾厄宫核心**：脾胃、消化系统 [来源: palace-interpretation.md]
- **倪师中医视角**：紫微属土，土主脾胃。紫微在疾厄宫，先天脾胃偏弱，消化吸收功能不佳。紫微为帝座，帝座不安则中焦失守——脾胃为后天之本，气血生化之源，中焦一乱则全身受累。
- **常见病症**：胃痛、消化不良、腹胀、胃酸过多
- **倪师针灸方案**：中脘（梅花灸）、关元、天枢、公孙、内关 [来源: ziwei-doushu/lib/nihai/renji.ts — ACU_EXPERIENCES id:14,18,19]
- **倪师方剂联动**：健胃散（各种胃病，温降调理胃气）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:78]
- **经方参考**：理中汤（中焦虚寒）、小建中汤（虚劳腹痛）[来源: ziwei-doushu/lib/nihai/renji.ts — CLASSIC_FORMULAS cf-10, cf-25]

### 天机（木·肝胆）

- **疾厄宫核心**：神经系统、肝胆 [来源: palace-interpretation.md]
- **倪师中医视角**：天机属木，木主肝胆。天机善变，在疾厄宫主肝气不舒、神经敏感。肝主疏泄，疏泄失常则气机郁滞，郁则化火，上扰神明则失眠多梦，横逆犯脾则纳差腹胀。
- **常见病症**：肝气郁结、肝炎、失眠、神经衰弱
- **倪师针灸方案**：肝关、行间（肝病）；三毛（灸）、神门（失眠）[来源: ziwei-doushu/lib/nihai/renji.ts — ACU_EXPERIENCES id:8,9,81]
- **倪师方剂联动**：护肝丸（见肝之病知肝传脾当先实脾）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:68]
- **经方参考**：小柴胡汤（和解少阳，往来寒热胸胁苦满）[来源: ziwei-doushu/lib/nihai/renji.ts — CLASSIC_FORMULAS cf-03]

### 太阳（火·心脏）

- **疾厄宫核心**：心脏、眼睛、血压 [来源: palace-interpretation.md]
- **倪师中医视角**：太阳属火，火主心。太阳在疾厄宫，心脏系统需重点关注。太阳庙旺则心火旺盛、精力充沛；太阳落陷则心阳不足，心脏压缩力不衡，可见心悸、手抖。太阳亦主目，落陷加煞注意眼疾。
- **常见病症**：冠心病、心绞痛、心律不齐、高血压
- **倪师针灸方案**：关元、巨阙、少府、涌泉、公孙（冠心病）；厉兑、人中、十宣放血（心绞痛急救）[来源: ziwei-doushu/lib/nihai/renji.ts — ACU_EXPERIENCES id:1,3]
- **倪师方剂联动**：乌金丸（心痛澈背）、心绞痛方（心脏动脉阻塞）、赤丸（心脏肥大）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:32,77,52]
- **经方参考**：炙甘草汤（心动悸脉结代）、四逆汤（回阳救逆）[来源: ziwei-doushu/lib/nihai/renji.ts — CLASSIC_FORMULAS cf-20, cf-05]
- **倪师特别提示**：煞星通过疾厄宫在午主心脏 [来源: ziwei-doushu/lib/nihai/tianji.ts — TIANJI_QUOTES]

### 武曲（金·肺）

- **疾厄宫核心**：呼吸系统、肺部、骨骼 [来源: palace-interpretation.md]
- **倪师中医视角**：武曲属金，金主肺。武曲刚毅，在疾厄宫主肺气肃降不利。肺主气、司呼吸、主皮毛，肺气不降则咳喘，肺津不布则皮肤干燥。武曲亦主骨骼，金主骨之坚硬度，需防骨质疏松。
- **常见病症**：咳嗽、气喘、肺癌、骨质疏松
- **倪师针灸方案**：中府、云门、孔最、公孙、内关（肺癌）；膻中、中府、云门（气喘）[来源: ziwei-doushu/lib/nihai/renji.ts — ACU_EXPERIENCES id:31,32]
- **倪师方剂联动**：骨损方（骨质疏松，肾主骨补肾强骨）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:63]
- **经方参考**：小青龙汤（外寒内饮咳喘痰多清稀）、麻杏甘石汤（汗出而喘）[来源: ziwei-doushu/lib/nihai/renji.ts — CLASSIC_FORMULAS cf-06, cf-15]

### 天同（水·肾）

- **疾厄宫核心**：泌尿系统、肾脏 [来源: palace-interpretation.md]
- **倪师中医视角**：天同属水，水主肾。天同在疾厄宫，先天肾气偏弱。肾为先天之本，主骨生髓，主水液代谢。天同福星，庙旺则虽有肾虚但可享安逸调养；落陷加煞则肾虚明显，小便不利、腰膝酸软。
- **常见病症**：肾虚、尿频、小便不利、前列腺问题
- **倪师针灸方案**：肾俞、京门、命门（肾虚）；中极、关元、阴陵泉（尿频）[来源: ziwei-doushu/lib/nihai/renji.ts — ACU_EXPERIENCES id:40,50]
- **倪师方剂联动**：肾积水方（恢复肾脏排尿功能）、金匮肾气丸（手脚冰冷强化肾脏）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:69,48]
- **经方参考**：肾气丸（肾阳不足，腰痛脚软小便不利）、真武汤（阳虚水泛）[来源: ziwei-doushu/lib/nihai/renji.ts — CLASSIC_FORMULAS cf-21, cf-09]

### 廉贞（火·心·血）

- **疾厄宫核心**：心脏、血液循环、性病 [来源: palace-interpretation.md]
- **倪师中医视角**：廉贞为囚星属火，在疾厄宫主心火亢盛或心火不足两端。廉贞桃花，亦主血分热毒，需防血液循环障碍及性传播疾病。廉贞在疾厄宫，心脏代偿性变化风险高，需警惕心脏肥大。
- **常见病症**：心脏肥大、血液循环障碍、性病
- **倪师方剂联动**：心脏肥大方（心阳不足代偿性变化）、赤丸（心脏肥大动脉剥离）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:87,52]
- **经方参考**：炙甘草汤（心动悸脉结代）[来源: ziwei-doushu/lib/nihai/renji.ts — CLASSIC_FORMULAS cf-20]

### 天府（土·脾胃）

- **疾厄宫核心**：脾胃、消化系统 [来源: palace-interpretation.md]
- **倪师中医视角**：天府属土，库星守成，在疾厄宫主脾胃运化功能偏于保守。天府庙旺则脾胃虽弱但守得住，不易大病；落陷则脾胃呆滞，运化无力，食积不化。天府为库，库满则安，库空则病——消化吸收功能是关键。
- **常见病症**：消化不良、腹胀、便秘
- **倪师针灸方案**：公孙、内关（消化不良）；支沟、照海（便秘）[来源: ziwei-doushu/lib/nihai/renji.ts — ACU_EXPERIENCES id:19,23]
- **倪师方剂联动**：健胃散（各种胃病）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:78]
- **经方参考**：理中汤（中焦虚寒）、小建中汤（虚劳腹痛）[来源: ziwei-doushu/lib/nihai/renji.ts — CLASSIC_FORMULAS cf-10, cf-25]

### 太阴（水·肾·妇科）

- **疾厄宫核心**：肾脏、泌尿、妇科 [来源: palace-interpretation.md]
- **倪师中医视角**：太阴属水，月星柔顺，在疾厄宫主肾水不足或水湿泛滥两端。太阴落陷加煞，女性需防妇科疾病（月经不调、子宫肌瘤），男性需防泌尿系统问题。太阴亦主情绪，落陷则情绪化影响健康。
- **常见病症**：妇科疾病、肾虚、水肿、情绪病
- **倪师针灸方案**：关元（灸）、中极（灸）、三阴交、血海（痛经）；隐白、行间（月经过多）[来源: ziwei-doushu/lib/nihai/renji.ts — ACU_EXPERIENCES id:53,55]
- **倪师方剂联动**：子宫症痼方（子宫肌瘤）、天青丸（痛经）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:8,36]
- **经方参考**：桂枝茯苓丸（瘀血阻滞胞宫）、温经汤（冲任虚寒久不受胎）[来源: ziwei-doushu/lib/nihai/renji.ts — CLASSIC_FORMULAS cf-22, cf-23]

### 贪狼（木·肝胆·生殖）

- **疾厄宫核心**：肝胆、生殖系统 [来源: palace-interpretation.md]
- **倪师中医视角**：贪狼属木（亦含水），桃花欲望之星，在疾厄宫主肝胆湿热与生殖系统疾病。贪狼多欲，过度的酒色财气伤肝耗肾。肝主疏泄，疏泄太过则相火妄动，疏泄不及则气机郁滞。
- **常见病症**：肝胆疾病、生殖系统疾病、性病
- **倪师针灸方案**：肝关、行间（肝病）；肝俞、胆俞、阳陵泉正下约一寸处胆石点（胆结石）[来源: ziwei-doushu/lib/nihai/renji.ts — ACU_EXPERIENCES id:8,13]
- **倪师方剂联动**：护肝丸（乙肝及各类肝病）、胆石方（胆结石胆囊息肉）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:68,14]
- **经方参考**：小柴胡汤（和解少阳）[来源: ziwei-doushu/lib/nihai/renji.ts — CLASSIC_FORMULAS cf-03]

### 巨门（土·呼吸道·暗疾）

- **疾厄宫核心**：呼吸道、食道、暗疾 [来源: palace-interpretation.md]
- **倪师中医视角**：巨门为暗星，在疾厄宫主暗疾难明。巨门属土，但暗星之性使其更偏向呼吸道与食道的隐匿性疾病——久咳不愈、咽中如有炙脔、食道不适。巨门口舌，亦需防因言语争辩导致的情志内伤。
- **常见病症**：慢性咳嗽、咽炎、食道问题、暗疾
- **倪师针灸方案**：太渊、灵墟、俞府、彧中（咳嗽）；丰隆（多痰）[来源: ziwei-doushu/lib/nihai/renji.ts — ACU_EXPERIENCES id:33,34]
- **倪师方剂联动**：皂荚丸（清除肺中吸烟浊痰）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:44]
- **经方参考**：小青龙汤（外寒内饮咳喘）[来源: ziwei-doushu/lib/nihai/renji.ts — CLASSIC_FORMULAS cf-06]

### 天相（水·皮肤·消化）

- **疾厄宫核心**：皮肤、消化系统 [来源: palace-interpretation.md]
- **倪师中医视角**：天相为印星属水，在疾厄宫主皮肤与消化系统。天相辅佐之性，在健康上表现为对环境变化敏感——皮肤过敏、消化不良多因脾胃功能不足。倪师认为"脾胃功能不足致过敏"。
- **常见病症**：皮肤过敏、消化不良、湿疹
- **倪师针灸方案**：公孙、内关（消化不良）；三间透合谷、筑宾、至阴、曲池、血海（皮肤痒）[来源: ziwei-doushu/lib/nihai/renji.ts — ACU_EXPERIENCES id:19,116]
- **倪师方剂联动**：皮肤过敏丸（食物过敏引起皮肤红疹瘙痒）、湿疹脓疮方（皮肤湿疹黄水疮）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:4,17]

### 天梁（土·脾胃·慢性病）

- **疾厄宫核心**：脾胃、慢性病 [来源: palace-interpretation.md]
- **倪师中医视角**：天梁为荫星属土，在疾厄宫主慢性脾胃疾病与老年病。天梁化解之性，在健康上表现为疾病迁延难愈但也不至于急危——慢性胃炎、慢性疲劳、老年退化性疾病。天梁亦主"荫"，长辈的体质遗传需关注。
- **常见病症**：慢性脾胃病、慢性疲劳、老年病
- **倪师针灸方案**：中脘、公孙、内关（胃病）；水分（灸）、公孙、消积（腹胀）[来源: ziwei-doushu/lib/nihai/renji.ts — ACU_EXPERIENCES id:14,17]
- **倪师方剂联动**：消渴方（糖尿病，脾运化不足致血糖失常）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:24]
- **经方参考**：苓桂术甘汤（痰饮病基础方）、五苓散（水气病）[来源: ziwei-doushu/lib/nihai/renji.ts — CLASSIC_FORMULAS cf-11, cf-12]

### 七杀（将星·外伤·急症）

- **疾厄宫核心**：外伤、手术、急症 [来源: palace-interpretation.md]
- **倪师中医视角**：七杀为将星，在疾厄宫主外伤、手术、急性病。七杀孤克冲动，健康上表现为突发性、剧烈性的病症——急性炎症、外伤出血、急腹症。七杀临身，倪师云"一辈子多败少成"，健康上亦多波折。
- **常见病症**：外伤、急性炎症、手术
- **倪师针灸方案**：委中、肾俞、大肠俞（腰痛）；环跳、阳陵泉、委中、悬钟（坐骨神经痛）[来源: ziwei-doushu/lib/nihai/renji.ts — ACU_EXPERIENCES id:97,98]
- **倪师方剂联动**：痛风丸（痛风关节红肿剧痛）、风湿丸（风湿性关节炎）[来源: ziwei-doushu/lib/nihai/renji.ts — HANTANG_FORMULAS id:27,28]
- **经方参考**：葛根汤（太阳阳明合病项背强）[来源: ziwei-doushu/lib/nihai/renji.ts — CLASSIC_FORMULAS cf-08]

### 破军（水·泌尿·皮肤）

- **疾厄宫核心**：泌尿系统、皮肤病 [来源: palace-interpretation.md]
