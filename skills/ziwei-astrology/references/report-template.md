# 完整命盘报告输出模板

> 本模板以示例命盘为标准，确保每次生成的报告内容丰富度、结构完整度和专业深度均达到同等水平。严格按照以下结构输出，不可省略任何章节或子节。

## 与示例的锚定关系

示例文件 `examples/命盘详析_1999年9月9日巳时男.md` 是报告质量的标准参照。以下为各章节与示例的对应关系：

| 报告章节 | 示例中对应位置 | 必须复刻的要素 | 可变部分 |
|---------|--------------|--------------|---------|
| 一、基本信息 | 示例L9-L39 | 16行完整表格+8步五行局推算 | 具体数值随命盘变化 |
| 二、十二宫排盘总表 | 示例L43-L63 | 8列表格+空宫说明 | 星曜组合随命盘变化 |
| 三、生年四化表 | 示例L66-L98 | 4条生年四化+48条宫干飞化+倪师断语 | 四化内容随年干变化 |
| 四、格局识别 | 示例L101-L145 | 三层结构表格（必须/加分/破格） | 格局种类随命盘变化 |
| 五、命宫总论 | 示例L147-L193 | 6个子节完整展开 | 主星特质随命盘变化 |
| 六、十二宫分论 | 示例L196-L298 | 12宫全部出现，重点宫7子节 | 各宫展开深度按分级制 |
| 七、四化飞化详析 | 示例L800-L884 | 飞忌/飞禄汇入统计+关键交互 | 飞化内容随命盘变化 |
| 八、大限运势 | 示例L886-L898 | 每个大限含表格+分析 | 大限数量和内容随命盘变化 |
| 九、流年要点 | 示例中5~7年 | 每年含四化分析 | 年份范围随当前年份调整 |
| 十、综合建议 | 示例中7个子章节 | 事业/财运/感情/健康/精神/规划/忠告 | 建议内容随命盘变化 |
| 十一、附录 | 示例尾部 | 术语解释+亮度对照+参考文献 | 基本固定 |

**质量判定标准**：生成的报告行数应≥1000行，与示例的内容密度和结构完整度相当。

## 来源标注规范（必读）

每条事实性内容必须标注来源文件，确保可追溯、不虚构。标注格式：`[来源: 仓库名/文件路径]`

**必须标注的场景**：
- 星耀亮度数据 → `[来源: iztro/src/data/stars.ts]`
- 四化对照表 → `[来源: iztro/src/data/heavenlyStems.ts]`
- 格局识别规则 → `[来源: ziwei-doushu/lib/ziwei/patterns.ts]`
- 倪师断语 → `[来源: ziwei-doushu/lib/nihai/tianji.ts]`
- 古籍引用 → `[来源: ziwei-doushu/lib/classics/gusuifu.ts]`
- 宫位解读规则 → `[来源: ziwei-doushu/lib/ziwei/constants.ts]`
- 星耀安星规则 → `[来源: iztro/src/star/location.ts]`

**不需要标注**：基本数学推算、AI综合分析（标注"AI综合分析"即可）、常识性描述

**HTML处理**：`[来源: xxx]` 标注在 HTML 中自动隐藏（display:none），仅在 Markdown 源文件中可见，供开发验证使用。

完整文件索引见 `references/source-repos.md`。

## 六、十二宫分论（必须全部12宫，按分级制展开）

十二宫按重要程度分为三级，展开深度不同。所有12宫都必须出现，但轻量宫可简化展开。

### 分级规则

| 级别 | 判定条件 | 必须子节 | 说明 |
|------|---------|---------|------|
| **重点宫** | 命宫、身宫所在宫、来因宫、生年四化落宫、格局相关宫 | 全部7子节 | 完整展开，不可省略 |
| **普通宫** | 有主星坐守但无特殊标记的宫位 | 5子节（主星特质与亮度、辅星影响、四化影响、三方四正综合、总评） | 长生十二神和杂耀可合并到总评中简述 |
| **轻量宫** | 空宫且无特殊标记 | 3子节（借星说明+主星特质、三方四正综合、总评） | 明确标注"此宫力量较轻，简述" |

**重点宫判定优先级**：命宫 > 身宫所在宫 > 来因宫 > 生年四化落宫 > 格局相关宫

**注意**：
- 即使是轻量宫，也必须在报告中出现，不可省略
- 轻量宫的借星说明必须写明借哪颗星、亮度如何、力量减半
- 如果某个轻量宫在特定命盘中有特殊意义（如流年触发），应升级为普通宫或重点宫

### 内容差异化指引（防止公式化）

> 12宫×7子节的结构确保完整性，但每个宫位的解读必须聚焦该宫的**独特信息**，避免跨宫位重复相同的解释框架。

**差异化原则**：

1. **主星特质子节**：不要重复该星的基本定义（如"太阳主贵"），而是聚焦**该星在这个特定宫位**的独特表现。例如：
   - 太阳在命宫 → "你天生有领导气质，但太阳为散财星，需看财帛宫配合"
   - 太阳在夫妻宫 → "你的另一半有贵气，但太阳在夫妻宫主配偶辛劳，需关注对方健康"
   - 同一颗星在不同宫位，解读方向完全不同

2. **辅星影响子节**：不要只列辅星名字+通用含义，必须说明**该辅星与主星的交互**。例如：
   - ❌ "左辅：贵人星，主助力"（通用描述，无差异化）
   - ✅ "左辅同会紫微于兄弟宫，增强兄弟中的贵人力量，但左辅为柔星，与紫微的刚性形成互补"（交互分析）

3. **四化影响子节**：飞化表格格式统一，但**解读**必须说明该飞化对该宫的具体影响路径。例如：
   - 飞忌入夫妻宫 → 不只写"感情有阻碍"，而是写明"XX宫干飞忌入夫妻，主因XX方面的问题影响感情"（从飞化源头追溯影响路径）

4. **三方四正子节**：不要机械列出三方四正位置，必须**分析关键组合**。例如：
   - ❌ "三方：巳（财帛·太阳）、酉（命宫·太阴）；四正：加丑（官禄·天梁）"（只列位置）
   - ✅ "日月分守命财两宫，太阴在命主富、太阳在财主贵，形成'日月并明'的基础条件，但需确认太阳是否庙旺"（分析组合含义）

5. **长生十二神子节**：不要只写长生神的通用含义，必须**关联该宫的实际影响**。例如：
   - ❌ "命宫坐沐浴，主变化"（通用描述）
   - ✅ "命宫坐沐浴，太阴在此更增感性，情绪起伏较明显，适合从事需要直觉和感受力的工作"（关联主星分析）

6. **总评子节**：必须综合该宫所有因素给出**独特结论**，不要用"综合来看，此宫吉凶参半"等模糊表述。每个宫的总评应该是该宫独有的结论，换一个宫就不能用同样的文字。

**跨宫去重检查**：生成12宫后，检查是否有两宫的总评使用了几乎相同的表述。如果有，说明差异化不足，需要重写使其各具特色。
