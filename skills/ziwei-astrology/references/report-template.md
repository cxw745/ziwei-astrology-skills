# 完整命盘报告输出模板

> 本模板以示例命盘为标准，确保每次生成的报告内容丰富度、结构完整度和专业深度均达到同等水平。严格按照以下结构输出，不可省略任何章节或子节。

## 来源标注规范（必读）

每条事实性内容必须标注来源文件，确保可追溯、不虚构。标注格式：`[来源: 仓库名/文件路径]`

**必须标注的场景**：
- 星耀亮度数据 → `[来源: iztro/src/data/stars.ts]`
- 四化对照表 → `[来源: iztro/src/data/heavenlyStems.ts]`
- 格局识别规则 → `[来源: ziwei-doushu/lib/ziwei/patterns.ts]`
- 倪师断语 → `[来源: ziwei-doushu/lib/nihai/tianji.ts]`
- 古籍引用 → `[来源: ziwei-doushu/lib/classics/gusuifu.ts]`
- 宫位解读规则 → `[来源: ziwei-doushu/lib/ziwei/constants.ts]`
- 星耀安星规则 → `[来源: iztro/src/star/location.ts]`

**不需要标注**：基本数学推算、AI综合分析（标注"AI综合分析"即可）、常识性描述

**HTML处理**：`[来源: xxx]` 标注在 HTML 中自动隐藏（display:none），仅在 Markdown 源文件中可见，供开发验证使用。

完整文件索引见 `references/source-repos.md`。

## 输出规范

1. 所有解读必须基于排盘结果，不可凭空臆断
2. 亮度等级：庙>旺>得>利>平>不>陷（iztro七级）或 bright>normal>dim（倪师三级）
3. 化忌入何宫，该宫位即为人生课题，需重点提示
4. 武曲/廉贞/七杀/破军在夫妻宫一律建议晚婚
5. 看婚姻必须同时看福德宫
6. 不确定的内容标注"无法确定"，不编造
7. 每个主题必须包含专业解读+通俗解析双层输出
8. 引用断语时标注来源（倪师原话/古籍出处/仓库规则）
9. 所有专项解读必须同时生成 .md 和 .html 两种格式
10. 大限详解必须标注当前大限位置
11. 流年详解必须结合大限背景分析
12. 流月详解必须结合流年和大限背景分析，不可孤立解读
13. **报告内容丰富度以示例（examples/）为标准**，不可省略任何子节
14. **十二宫分论必须全部12宫**，不可省略任何宫位
15. **每个宫位必须包含7个子节**：主星特质与亮度、辅星影响、杂耀影响、四化影响(飞化表格)、三方四正综合、长生十二神暗示、总评(专业+通俗)
16. **宫干飞四化总表必须完整**，12宫×4化=48条不可遗漏
17. **倪师断语必须引用**，每个关键宫位和四化都应有倪师原话支撑
18. **来源标注必须完整**，每条事实性内容必须标注 `[来源: 仓库名/文件路径]`，无法追溯的标注"AI推断"
