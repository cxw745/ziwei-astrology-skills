# 完整命盘报告输出模板

## 报告结构

生成命盘报告时，严格按照以下十一章节结构输出。每个章节都有明确的必填内容，确保报告完整且专业。

---

### 一、基本信息

ALWAYS 使用此表格格式：

| 项目 | 内容 |
|------|------|
| 阳历 | YYYY年M月D日 |
| 农历 | 二〇〇二年七月十七 |
| 干支纪年 | 壬午年 戊申月 乙丑日 丁丑时 |
| 时辰 | 丑时（01:00~03:00） |
| 性别 | 男（阳男）/ 女（阴女） |
| 生肖 | 马 |
| 星座 | 处女座 |
| 命宫地支 | 未 |
| 身宫地支 | 酉 |
| 命主 | 武曲 |
| 身主 | 火星 |
| 五行局 | 水二局 |

附五行局推算过程（让用户理解计算逻辑）。

### 二、十二宫排盘总表

完整12宫表格，每宫包含：
- 宫名（命宫、兄弟宫、……、父母宫）
- 天干地支
- 主星（含亮度标注与四化标注，如"天府（庙）""武曲（化忌）"）
- 辅星
- 杂耀
- 长生12神
- 博士12神
- 大限范围（如"2~11岁"）
- 是否身宫/来因宫（标注★）

### 三、生年四化表

| 四化 | 星曜 | 所在宫位 | 含义 |
|------|------|---------|------|
| 化禄 | XXX | XX宫 | 增益、财运 |
| 化权 | XXX | XX宫 | 权力、掌控 |
| 化科 | XXX | XX宫 | 名声、贵人 |
| 化忌 | XXX | XX宫 | 阻碍、课题 |

### 四、各宫位详析

每个宫位必须包含以下内容，分专业解读和通俗解析两层：

```
#### X宫（天干地支）

**主星**：XXX（亮度）
**辅星**：XXX
**四化**：XXX

【专业解读】
（术语严谨的分析，引用古籍和倪师断语）

【通俗解析】
（日常比喻和可执行建议）
```

解读维度（每个宫位必须覆盖）：
1. 主星特质与亮度解读
2. 辅星影响
3. 杂耀影响
4. 四化影响（生年四化+宫干飞化）
5. 三方四正综合
6. 长生12神暗示
7. 健康提示（疾厄宫及相关宫位）

### 五、格局分析

逐一列出识别到的格局，每个格局包含：

```
#### 格局名称（等级：excellent/good/neutral/caution）

- **必须条件**：XXX ✅/❌
- **加分项**：XXX ✅/❌
- **破格条件**：XXX ✅/❌
- **古籍出处**：《XXX》
- **综合解读**：XXX

【专业解读】……

【通俗解析】……
```

等级说明：
- excellent：必须条件全满，加分项多，无破格
- good：必须条件全满，加分项少或轻微破格
- neutral：必须条件基本满足但有破格
- caution：必须条件未完全满足

## 输出规范

1. 所有解读必须基于排盘结果，不可凭空臆断
2. 亮度等级：庙>旺>得>利>平>不>陷（iztro七级）或 bright>normal>dim（倪师三级）
3. 化忌入何宫，该宫位即为人生课题，需重点提示
4. 武曲/廉贞/七杀/破军在夫妻宫一律建议晚婚
5. 看婚姻必须同时看福德宫
6. 不确定的内容标注"无法确定"，不编造
7. 每个主题必须包含专业解读+通俗解析双层输出
8. 引用断语时标注来源（倪师原话/古籍出处/仓库规则）
