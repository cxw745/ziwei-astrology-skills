# 天机星核心断语

> 搜索时间: 2026-05-22
> 来源: ziwei-doushu本地仓库

## 基本特质

天机为智慧星，主善变机灵，化气为善。落命主聪明机变、宜辅佐策划。

- 关键词：智慧·机变·谋略
- 星性：吉星
- 五行：木
- 亮度：巳亥卯酉庙旺，丑未平，寅申陷，子辰午戌平

## 十二宫断语

**命宫**：天机入命，聪明善谋，宗教哲学缘深，但善变不定，不宜独坐。天机太阴天同天梁四星齐入命迁财官，为"机月同梁"格，文质彬彬、聪慧善谋，最适合公职、学术、文艺、医疗、服务等需稳定累积的行业。

**夫妻宫**：婚姻多变，宜年龄差较大的配偶。见禄存或化禄：感情尚可维持；会太阴：增添细腻温柔。化忌或会煞：感情变化大，易有分离；天机善变，配偶对感情举棋不定。配偶聪明多变，心思细腻，宗教哲学缘深，有点神经质。宜年龄差异较大（差6岁以上），可降低双方变化冲突。

**官禄宫**：天机入官禄，宜辅佐策划、参谋幕僚，不宜独当一面。

**财帛宫**：天机主智不主财，理财靠脑力，见禄存方可稳定。

**迁移宫**：天机在迁移，出外多变，宜从事需要灵活应变的工作。

## 倪师天纪断语

1. 天纪DVD03："天机善星智慧"——天机为善星，主智慧机变
2. 夫妻宫断语："天机善变，不宜独坐，婚姻充满变化"
3. 天纪DVD06："化忌主劫杀"——天机化忌（戊干）为劫杀之象
4. 命宫为本三方为用——天机入命三方宜见太阴天同天梁，构成机月同梁稳定格局

## 四化影响

天机参与四化，为十四主星中化最多的星之一：

- **乙干化禄**：天机化禄，智慧生财，谋略得财，宜策划、咨询、技术类生财
- **丙干化权**：天机化权，智慧得权，谋略增强，宜参谋决策、幕后操控
- **丁干化科**：天机化科，智慧得名声，贵人相助，宜学术、文教
- **戊干化忌**：天机化忌，善变过度，谋略反成算计，多思多虑反误事，劫杀之象

天机四化齐全，吉凶皆可，关键看落宫与三方配合。化忌时尤需注意感情与事业的多变波折。
