# 太阴星核心断语

> 搜索时间: 2026-05-22
> 来源: ziwei-doushu本地仓库

## 基本特质

太阴为月亮富贵星，主田宅富贵，化气为富。落命主感情细腻、女命最吉。

- 关键词：柔美·财富·阴柔
- 星性：吉星
- 五行：水
- 亮度：太阴亮度极度依赖宫位——亥子丑庙旺，寅戌旺，卯辰巳午未申酉皆为陷或不。与太阳互为对星，太阴庙旺时恰逢太阳落陷，反之亦然。

## 十二宫断语

**命宫**：太阴入命，温柔秀气，感情细腻，女命最吉。庙旺时持家有方、田宅运佳；落陷时情绪化、消极、优柔寡断。太阴落陷坐命，心性不定，做事反复。

**夫妻宫**：喜清秀温柔配偶；落陷加煞则感情多变。庙旺（子至午）见吉：配偶秀气有成就，男命妻美；女命：自身秀美有气质。落陷（未至亥）：感情易变，配偶健康欠佳；化忌（男命尤忌）：婆媳不和，妻子与母亲必起冲突；遇火铃：感情重大变故。配偶温柔秀气，细腻敏感，重感情，但有时情绪化。无特定约束，但落陷时宜晚婚。

**官禄宫**：太阴入官禄，宜文艺、服务、不动产、财务管理，庙旺时事业顺遂。

**财帛宫**：太阴为富星，入财帛宫理财细腻，庙旺时田宅财运佳，落陷则积蓄困难。

**田宅宫**：太阴为田宅主，入田宅宫房产运佳，庙旺时置产顺利，落陷则居家不安。

**疾厄宫**：太阴属水主肾，入疾厄需防肾脏、泌尿系统、妇科疾病，落陷时尤甚。

**福德宫**：太阴入福德，精神世界细腻丰富，落陷则内心空虚、容易抑郁焦虑。

## 倪师天纪断语

1. 夫妻宫断语："男人的命，最怕太阴化忌，婆媳不和，太太跟妈妈一定不和的"
2. 太阴落陷需兼看太阳亮度，若太阳亦陷则"日月反背"，一生劳碌
3. 日月同宫：太阳太阴于丑/未宫同宫，阴阳平衡，文武兼备
4. 日月夹命：太阳太阴分居命宫两侧夹照，光明磊落，一生贵人相助
5. 太阴入命女孩最漂亮——倪师论断太阴庙旺入命的女性容貌秀美

## 四化影响

太阴参与四化：

- **丁干化禄**：太阴化禄，富星得禄，田宅财运大增，女命尤吉，理财能力增强
- **戊干化权**：太阴化权，柔中带刚，理财掌控力增强，女命主事能力提升
- **乙干化忌**：太阴化忌，富星化忌为大凶——男命婆媳不和、妻子与母亲必起冲突；女命感情波折、财务受损
- **庚干/癸干化科**：太阴化科，柔美得名声，贵人相助，宜文艺、学术

太阴化忌是倪师反复强调的凶象，尤其男命太阴化忌，婆媳关系几乎无解。太阴落陷加化忌，凶性加倍，需特别留意健康与感情。
