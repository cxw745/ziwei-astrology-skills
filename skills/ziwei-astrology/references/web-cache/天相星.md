# 天相星核心断语

> 搜索时间: 2026-05-22
> 来源: ziwei-doushu本地仓库

## 基本特质

天相为印星辅佐，主忠厚老实，化气为印。落命主品行端正、宜行政法务。

- 关键词：辅佐·行政·印绶
- 星性：吉星
- 五行：水

## 十二宫断语

**命宫**：天相入命，品行端正，忠厚老实，善于协调。天相为印星，宜行政、法务、辅佐之职。天相适应性强，与任何星搭配皆可协调。

**夫妻宫**："亲上加亲"良缘，夫唱妇随，合作型婚姻。见辅弼双全：感情忠诚，婚姻稳固；配偶正直踏实；天相三合见禄：财禄可期。辅弼单星：可能预示再婚；遇煞多：感情中压抑委屈，不善表达。配偶正直踏实，守信用，不喜欢冲突，善于协调，是绝佳的生活伴侣。多为同学、同事、街坊等熟识关系发展，宜夫妻合作共事。

**官禄宫**：天相入官禄，宜行政管理、法务、人事、辅佐之职，稳重可靠。

**财帛宫**：天相主印不主财，见禄存则稳定，善于守成。

**迁移宫**：天相在迁移，出外有贵人，宜行政、协调类工作。

## 倪师天纪断语

1. 府相朝垣格：天府天相分守命宫三方四正，文武并济、权印双辉，主一生衣食丰足、地位崇高
2. 廉贞天相格：廉贞天相同宫，印绶格局，主秉公处事、清廉之名，宜任公职、行政管理、法务、企划
3. 天相为印星，最喜与禄存同宫或会照，形成"印禄交辉"之象

## 四化影响

天相不参与四化。

天相为印星，本身不化禄权科忌，其吉凶取决于同宫及三方四正的会照星曜。天相最喜见禄存或化禄，形成"印禄交辉"；最忌与擎羊同宫（廉杀羊倾向），或被煞星夹制。天相的稳定性使其成为十四主星中适应性最强的星，与任何星搭配皆可协调。
