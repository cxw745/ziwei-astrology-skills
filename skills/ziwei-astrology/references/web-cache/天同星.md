# 天同星核心断语

> 搜索时间: 2026-05-22
> 来源: ziwei-doushu本地仓库

## 基本特质

天同为福星，主温和享乐，化气为福。落命主性情温和、有福气。

- 关键词：温和·享福·随缘
- 星性：吉星
- 五行：水
- 亮度：子卯午酉庙旺，丑辰未戌平，寅巳申亥陷

## 十二宫断语

**命宫**：天同入命，性情温和，乐观随和，有福气。天同天梁同宫，福星与荫星共会，主宽厚和善、乐于助人，宜医疗、教育、宗教、社会公益。但偏温和保守，难成大富大贵之局。

**夫妻宫**：配偶温和享乐，宜年龄差较大，晚婚为吉。见禄存或化禄：配偶温和带财，家庭安稳；与太阴同：感情温柔甜蜜。化忌：感情刚开始尚可，逐渐转淡，因协调不良引起怨怼；遇煞多：懒散变成负担。配偶温和善良，乐观随和，但可能懒散，享乐主义较强。男娶比自己小、女嫁比自己大，年龄差8年以上为最佳结发。

**官禄宫**：天同入官禄，宜文教、服务、医疗等温和行业，不宜竞争激烈的岗位。

**财帛宫**：天同主福不主财，见禄存方可稳定，否则容易满足于现状。

**福德宫**：天同入福德，精神世界安逸享乐，但遇煞则懒散消极。

**疾厄宫**：天同属水主肾，入疾厄需防肾脏、泌尿系统、妇科疾病。

## 倪师天纪断语

1. 天同天梁格：天同天梁同宫，福星与荫星共会，主宽厚和善
2. 机月同梁格：天机太阴天同天梁四星齐入命迁财官，文质彬彬、聪慧善谋
3. 天同化忌（庚干）：感情刚开始尚可，逐渐转淡，因协调不良引起怨怼

## 四化影响

天同参与三化：

- **丙干化禄**：天同化禄，福星得禄，温和带财，享受生活的同时财运稳定
- **丁干化权**：天同化权，福星得权，温和中增加果断力，不再一味随缘
- **庚干化忌**：天同化忌，福星化忌，享乐变消极，感情由甜转淡，协调不良引起怨怼

天同化忌时尤需注意感情与精神状态，容易因懒散消极而错失良机。
