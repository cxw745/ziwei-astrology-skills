# 七杀星核心断语

> 搜索时间: 2026-05-22
> 来源: ziwei-doushu本地仓库

## 基本特质

七杀为将星，主孤独果决冒险，化气为肃杀。落命主刚毅果决、宜军警创业。

- 关键词：将星·果决·孤克
- 星性：凶星
- 五行：金

## 十二宫断语

**命宫**：七杀入命，刚毅果决，孤克冒险，宜军警、创业。七杀属杀破狼格局之首，永远与破军、贪狼同在三方四正，构成变动格局。七杀入命得辅弼魁钺，反为将才，开创有功；无辅弼则孤高自傲，一生多败少成。

**夫妻宫**："鸳衾半冷"——聚少离多，宜晚婚30岁后。庙旺（寅申宫）：配偶虽刚强但忠诚，一旦投入则全力付出；化禄相助：减轻孤克。遇煞：感情表面和谐内心不满，男命主二娶；女命宜偏房继室；卯酉宫（武曲七杀）：婚姻运最差。配偶刚强孤僻，一见钟情快，离开也快，恋爱冷热均快。一律宜晚婚，30岁后婚姻较稳固；早婚多刑克。

**官禄宫**：七杀入官禄，宜军警、创业、独立事业，有冲杀之力。

**财帛宫**：七杀主开创不主守财，财运大起大落，赚钱靠拼搏。

**迁移宫**：七杀在迁移，出外波折多，但庙旺时异乡创业有成。

**疾厄宫**：七杀属金主肺，入疾厄需防呼吸系统、肺部疾病，煞星通过疾厄宫在午主心脏，在丑主肝。

## 四化影响

七杀不参与四化。

七杀为将星，本身不化禄权科忌，其吉凶完全取决于同宫及三方四正的会照星曜。七杀最喜见禄存或化禄，减轻孤克之性；最忌见煞星齐聚，则刚愎自用、血光意外。七杀入命需辅弼配合方显将才，无辅弼则"在野孤将"，一生多败少成。
