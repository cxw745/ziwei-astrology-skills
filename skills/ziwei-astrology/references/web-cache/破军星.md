# 破军星核心断语

> 搜索时间: 2026-05-22
> 来源: ziwei-doushu本地仓库

## 基本特质

破军为破坏创新星，主六亲缘薄，化气为耗。落命主开创变动、宜技术专长。

- 关键词：开创·变动·破坏
- 星性：凶星
- 五行：水

## 十二宫断语

**命宫**：破军入命，开创变动，六亲缘薄，宜技术专长。破军属杀破狼格局之一，永远与七杀、贪狼同在三方四正，构成变动格局。破军入命一生变动多、不甘平凡，宜创业、技术、独立事业。中年后才能稳定守成，年轻时易因冲动失利。

**夫妻宫**：婚姻破耗之星，无人出其右，追求无约束感情。化禄：破而后立，感情历经波折反而能走到最后；英星入庙：配偶英挺有个性。化忌：破坏殆尽，多一婚或不婚；紫微破军（丑未）：不加煞亦克，加煞必离；与廉贞：水中做坟墓；中年后有分床分居之象。配偶追求自由，不喜约束，勇于突破，但婚姻观念薄弱，一生变动大。婚前易一见钟情或草率结婚，宜拉长相处时间再做决定。

**官禄宫**：破军入官禄，宜创业、技术革新、独立事业，有破坏重建之能。

**财帛宫**：破军主耗不主聚财，财运先破后立，见化禄则破而后立可得财。

**迁移宫**：破军在迁移，出外多变，宜远赴他乡发展，但波折多。

**子女宫**：破军入子女宫，与子女缘薄，子女个性叛逆独立。

## 倪师天纪断语

1. 天纪DVD04："杀破狼三星一定同在三方"——破军永远与七杀、贪狼同在三方四正
2. 夫妻宫断语："廉贞破军在夫妻宫，水中做坟墓；破军是婚姻破坏力最强的星"
3. 杀破狼格局：七杀、破军、贪狼三星会命，开创闯荡之命格，一生变动多、不甘平凡
4. 破军入命者一生破而后立，适合不断创新的行业

## 四化影响

破军参与两化：

- **癸干化禄**：破军化禄，破坏之后得财，破而后立，历经波折反而能走到最后，宜创业、技术革新
- **甲干化权**：破军化权，破坏之中得权，掌控变动的能力增强，宜领导变革、创新事业

破军不化科亦不化忌，但破军本身即为耗星，其破坏性不需化忌来加强。破军化禄时最为吉利，破坏之后得以重建，先破后立。破军化权时掌控力增强，但变动性依然强烈。
