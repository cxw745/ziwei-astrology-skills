# 贪狼星核心断语

> 搜索时间: 2026-05-22
> 来源: ziwei-doushu本地仓库

## 基本特质

贪狼为桃花欲望星，多才多社交，化气为桃花。落命主多才艺、社交广。

- 关键词：欲望·桃花·多才
- 星性：中性
- 五行：木

## 十二宫断语

**命宫**：贪狼入命，多才艺、社交广、欲望旺盛。命宫贪狼文武双全。贪狼与火星同宫或会照，为"火贪格"，主突发横财、突如其来的机遇。贪狼与铃星同宫或会照，为"铃贪格"，同样主横发。武曲贪狼会命，为"武贪格"，古书云"武贪不发少年人"——三十岁后方能厚积薄发。

**夫妻宫**：桃花最旺，婚姻不稳，外遇风险高。化禄：配偶才艺佳，风情万种，感情甜蜜（但外遇风险不减）；遇化科：减少外遇。化忌：多二次婚姻；紫微贪狼（卯酉）：配偶多外出，有外遇之兆；遇四煞：必生离；午宫贪狼（武官星）：反主武职配偶，较稳定。配偶才艺超群，社交能力强，异性缘极好，但欲望旺盛，难以约束。早婚感情多变，宜晚婚；婚前务必了解对方异性关系。

**官禄宫**：贪狼入官禄，宜演艺、社交、销售、娱乐业，火贪格主暴发。

**财帛宫**：贪狼主欲望财，见化禄或火铃则横发，但来得快去得也快。

**迁移宫**：贪狼在迁移，出外社交广，异性缘佳，但需防桃花纠纷。

## 倪师天纪断语

1. 天纪DVD04："贪狼桃花星"——贪狼为桃花欲望星
2. 天纪DVD04："杀破狼三星一定同在三方"——贪狼永远与七杀、破军同在三方四正
3. 夫妻宫断语："贪狼除了指桃花星，也指酒色财气赌，统统在贪狼里面；贪狼在午宫是武官星，不要随便批桃花"
4. 火贪格/铃贪格：贪狼遇火星/铃星，古书云"贪狼遇火铃，必发横财"
5. 武贪格：古书云"武贪不发少年人"——三十岁后方能厚积薄发

## 四化影响

贪狼参与三化：

- **戊干化禄**：贪狼化禄，桃花生财，人脉变财脉，社交广则财源广，但外遇风险不减
- **己干化权**：贪狼化权，欲望得权，掌控力增强，宜社交型事业，才艺发挥更佳
- **癸干化忌**：贪狼化忌，桃花化忌，欲望受阻，感情多波折，多二次婚姻

贪狼化忌时感情波折最大，需特别注意婚姻稳定性。贪狼在午宫为武官星，不可简单批为桃花。
