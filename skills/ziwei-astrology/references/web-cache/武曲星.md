# 武曲星核心断语

> 搜索时间: 2026-05-22
> 来源: ziwei-doushu本地仓库

## 基本特质

武曲为财星，主刚毅果决，化气为财。落命主理财能力强、宜实业金融。

- 关键词：财富·刚毅·果断
- 星性：中性
- 五行：金
- 亮度：寅申丑未庙旺，子卯午酉平，辰戌巳亥陷

## 十二宫断语

**命宫**：武曲入命，刚毅果决，理财能力强，宜实业金融。武曲独坐需防孤克，见禄存或化禄方为财格。武曲七杀同宫，将星配财星，主果决刚毅、理财能力强，适合金融、军警、创业。但忌见化忌煞星，否则凶险。

**夫妻宫**：寡宿之星，婚姻刑克，一律宜晚婚。武曲化禄：配偶有财能力，但男命反嫌妻太能干；见禄存夹辅：婚姻稳固有财。化忌：孤寡，难婚，或配偶身有残疾；武曲七杀（卯酉宫）：婚姻恶劣之兆；遇四煞任一：主离婚；武曲破军：见煞忌刑曜婚姻必不利。配偶刚烈独立，说话直接，不善表达情感，经济能力强但性格较孤克。武曲系一律建议30岁以后结婚，早婚早散。

**官禄宫**：武曲入官禄，宜金融、实业、军警、创业，化权时事业掌控力极强。

**财帛宫**：武曲为正财星，入财帛宫理财有方，见禄存或化禄为财格。

**疾厄宫**：武曲属金主肺，入疾厄需防呼吸系统、肺部疾病，化忌时尤甚。

## 四化影响

武曲参与四化：

- **己干化禄**：武曲化禄，正财星得禄，理财能力大增，宜实业、金融，财源稳定
- **庚干化权**：武曲化权，财星得权，掌控力增强，宜管理、决策岗位
- **甲干化科**：武曲化科，财星得名声，因专业理财能力获认可
- **壬干化忌**：武曲化忌，财星化忌为大凶——理财受阻、投资失利、钱财被劫。武曲化忌是"刑囚"之象，不论落在何宫皆主"孤"——孤于亲、孤于财、孤于情

武曲化忌在夫妻宫，倪师一律建议晚婚，30岁前结婚几乎必离。武曲化忌遇煞星齐聚，需防重大财务损失或法律纠纷。
