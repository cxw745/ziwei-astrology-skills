# Q&A 正反双审规则

> 灵感来源：vedic-astro-skills 的 Q&A 双审机制（dual-review Q&A），适配紫微斗数体系重写。

## 适用范围

继续提问（Step 5）中，回答任何**判断性问题**时必须执行正反双审。

判断性问题的特征：用户在问"好不好""适不适合""会不会""能不能"等需要给出倾向性判断的问题。

非判断性问题（如"XX星在XX宫是什么意思"）只需客观解释，不需要双审。

## 双审格式

回答判断性问题时，必须同时列出支持和制约的数据：

```
### 问题：{用户的问题}

**支持[X]的数据：**
- {排盘数据1} → {解读}
- {排盘数据2} → {解读}

**制约[X]的数据：**
- {排盘数据3} → {解读}
- {排盘数据4} → {解读}

**综合判断：** {基于数据的客观判断，不偏向任何一方}
```

## 数据源优先级

| 优先级 | 数据源 | 用途 |
|--------|-------|------|
| 1 | 已生成的报告章节 | 直接引用已有结论，不重新推导 |
| 2 | chart-data.json | 补充报告未覆盖的细节 |
| 3 | references/ | 补充断语和规则 |
| 4 | 验前事信号修正日志 | 辅助判断信号表达方向 |

禁止行为：
- 忽略已有报告结论，从排盘数据自己重新分析
- 只看报告摘要，不回读排盘数据验证
- 编造报告中不存在的结论

## 禁止"卖乐观"或"卖悲观"

| 倾向 | 表现 | 纠正 |
|------|------|------|
| 卖乐观 | 只列支持数据，弱化/忽略制约数据 | 制约数据至少1条 |
| 卖悲观 | 只列制约数据，弱化/忽略支持数据 | 支持数据至少1条 |
| 讨好 | 用户想听好话→只列支持→❌ | 无论用户情绪，正反都列 |
| 恐吓 | 用户焦虑→只列制约→❌ | 无论用户情绪，正反都列 |

| 问题类型 | 支持数据来源 | 制约数据来源 |
|---------|------------|------------|
| 事业运 | 官禄宫吉星/化禄/格局 | 官禄宫煞星/化忌/破格 |

## 与盲审原则的配合

Q&A阶段允许参考对话中用户的问题背景来**理解问题**，但**结论仍必须基于排盘数据**：

```
✅ 用户问"我适合做心理咨询吗" → 理解用户在问职业方向 → 基于官禄宫+财帛宫数据回答
❌ 用户问"我适合做心理咨询吗" → 知道用户学过心理学 → 把官禄宫往心理学方向靠
```

反锚定自检：如果推导过程中出现"因为用户说过X所以Y"的逻辑，立即停止并重新从盘面推导。

## 两层分析模式（盲审+结合自述）

当用户在追问中提供了个人经历、偏好、行为描述等自述信息时，分析必须分两层进行：

**第一层：纯命盘推导（盲审层）** — 从排盘数据独立推导，不引用用户自述

**第二层：结合自述解读（映射层）** — 在第一层基础上，将用户自述映射为命盘倾向的具体表现

**关键约束**：
- 推导方向：命盘→自述（合规），自述→命盘（违规）
- 第二层以"**结合自述**："开头，与第一层明确分开
- 措辞："你的自述是这个命盘倾向的一种具体表现方式"，而非"你的自述验证了命盘"
- 没有用户自述时只写第一层

**示例**：

```
❌ 违规（自述→命盘）：
你描述的"被踩脸"说明你命盘里武曲化忌的渴望——你的行为验证了命盘。

✅ 合规（命盘→自述）：
武曲化忌在夫妻宫，命主在感情中需要"被更强力量掌控"。

**结合自述**：你描述的"被踩脸、被打巴掌"——这些行为的共同点
是"对方的力量完全压过你"。武曲化忌在夫妻宫的人，在感情中天然
需要"被更强力量掌控"，你的自述是这个命盘倾向的一种具体表现方式。
```

## 写作规范（防止错误归因和绝对论断）

### 规则1：命盘是参考，不是原因

命盘描述倾向和特征，是参考工具，不是行为的原因。禁止把个人选择归因于命盘。

| 错误写法 | 正确写法 | 问题 |
|---------|---------|------|
| "不喜欢写代码不是你的问题，是命盘里没有一颗星支持你" | "命盘中与纯技术深钻相关的星曜较少" | 错误归因，帮人找借口 |
| "这不是意志力的问题，是贪狼的运行机制" | "贪狼在身宫的人普遍兴趣广泛但持久力偏弱" | 错误归因，把原因归给命盘 |
| "不是性格缺陷，是化忌的能量模式" | "化忌在夫妻宫的人，感情中容易有执念倾向" | 错误归因，把个人特质归为命盘决定 |
| "这不是泼冷水，是排盘数据的诚实结论" | "从排盘数据看，现阶段脱离职场的风险较高" | 多余的辩解式前缀 |

核心原则：**描述命盘显示什么，不解释为什么是这样。** 命盘不能解释"为什么你不喜欢写代码"，它只能告诉你"命盘中技术深钻相关的星曜较少"。

### 规则2：描述倾向，不做绝对论断

命盘描述倾向和概率，不替人做决定。禁止用绝对指令替用户下结论。

| 错误写法 | 正确写法 | 问题 |
|---------|---------|------|
| "必须在大平台做执行型产品经理，不要去创业公司" | "命盘显示你的个性更符合大平台的执行型产品经理角色" | 绝对论断，替人做决定 |
| "一律建议晚婚" | "晚婚（28岁后）的婚姻稳定性更高" | 绝对论断 |
| "绝不可裸辞搞副业" | "没有稳定收入来源时搞副业风险较大" | 绝对论断 |
| "你只需要做一件事" | "一个可能有效的切入点是" | 绝对论断 |

替换词表：
- "必须" → "更符合""倾向于""更适合"
- "不能""不要" → "风险较大""需谨慎""可能遇到挑战"
- "一定要" → "建议""可以考虑"
- "只需要" → "一个重要的方向是"

### 规则3：慎用"不是…而是…"句式

"不是A而是B"容易制造虚假对比和错误归因，大量堆砌会让解读显得武断。

**判断标准：用得对不对，有没有必要。** 每次使用前问自己三个问题：
1. A和B是不是真的对立关系？（如果不是，这个句式就是虚假对比）
2. 用"不是…而是…"是否比直接说B更准确？（如果直接说B更清晰，就不需要这个句式）
3. 这个句式是否在把原因归给命盘？（如果是，禁止使用）

**可以使用的情况**（确实存在明确对比关系，且有必要澄清误解）：
- "化禄不是好运的保证，而是机遇的信号" → 两个概念确实在对比，逻辑对等，澄清常见误解 ✅
- "天府不是不温暖，而是温暖得慢" → 对比双方逻辑对等，澄清误解 ✅

**禁止使用的情况**（虚假对比或错误归因）：
- "这不是'选不选'的问题，而是'选了之后怎么扛'的问题" → 两者不是对立关系，选不选和怎么扛是两个独立维度 ❌
- "不是意志力的问题，是贪狼的运行机制" → 错误归因，把原因归给命盘 ❌
- "这不是泼冷水，是排盘数据的诚实结论" → 防御性前缀，虚假对比，直接说结论即可 ❌

**写作提醒**：写作时注意控制"不是…而是…"的使用频率。如果发现一段话里反复出现这个句式，大概率是在用它"制造气势"而非"澄清事实"，应考虑改写。

**审查环节**：最终审查时，逐条检查每个"不是…而是…"——问"有没有这么一回事""有没有必要这样说"。不恰当的改写为直接表述。

### 规则4：倪师断语的引用规范

倪师断语是参考，不是金科玉律。引用倪师断语时：
- 标注[来源: 倪海厦《天纪》]
- 不把倪师断语当作绝对真理来下结论
- 可以用"倪师认为""倪师的观点是"等表述，不用"倪师说必须""倪师说绝不可"
