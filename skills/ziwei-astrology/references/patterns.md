## 识别原则

来源：`https://github.com/Renhuai123/ziwei-doushu` 的 `lib/ziwei/patterns.ts`

1. 古书条件优先：每个格局列出"必须/加分/破格"三层结构，出处可考
2. 倪师立场：不使用宫干自化、大限四化、来因宫等飞星派工具
3. 庙旺利陷：用 brightness 字段（bright=庙旺、normal=平、dim=陷）
4. 三方四正会照：命宫 + 财帛 + 官禄 + 迁移
5. 夹宫：命宫前后两宫

## 格局判断三层结构

每个格局包含：
- **必须条件（required）**：格局成立的前提，缺一不可
- **加分条件（bonus）**：增强格局力量，越多越吉
- **破格条件（breaking）**：削弱或破坏格局，触发则降级

## 上格

大贵大富之格，古书明确记载，条件严格。

### 1. 君臣庆会

紫微入命，左辅右弼同会三方四正，帝王得贤臣辅佐，主大富大贵、统御之命。一生贵人不绝，宜走政商高位、跨界领袖之途。

| 层次 | 条件 |
|------|------|
| 必须 | 紫微入命；左辅右弼同会三方四正 |
| 加分 | 再会文昌或文曲；魁钺贵人加照；紫微化权 |
| 破格 | 地空地劫双夹会照（紫微忌空劫） |

出处：《紫微斗数全书·君臣庆会格》

### 2. 紫府同宫

紫微天府同入命宫，帝相并临，尊贵之命。主品行端正、衣食无忧、有领导才能，宜担任要职。需要左右辅弼来配合方为完整大格。若紫府同宫但未坐命，主一生有贵人贵气依托，但本身不一定大富贵。

| 层次 | 条件 |
|------|------|
| 必须 | 紫微天府同入命宫（限寅申宫） |
| 加分 | 左辅右弼同会；再会昌曲 |
| 破格 | 紫府宫坐空劫（破紫府之贵气）；紫府宫见双煞同坐 |

出处：《紫微斗数全书·紫府同宫格》

### 3. 府相朝垣

天府天相分守命宫三方四正，文武并济、权印双辉，主一生衣食丰足、地位崇高。古书云"府相朝垣千钟食禄"，常见于政界、企业管理者。

| 层次 | 条件 |
|------|------|
| 必须 | 天府坐命三方；天相坐命三方；两星不同宫 |
| 加分 | 命宫见禄（禄存或化禄）；再会左辅 |
| 破格 | 命宫坐煞星；三方四正煞星过多（≥3颗四煞） |

出处：《紫微斗数全书·府相朝垣格》

### 4. 阳梁昌禄

太阳、天梁、文昌、禄存四星齐会命宫三方，号称"科举之星"，主清贵显达、考运极佳，宜走学术、文教、研究、专业认证之路，一生功名易就。

| 层次 | 条件 |
|------|------|
| 必须 | 太阳会命宫三方；天梁会命宫三方；文昌会命宫三方；禄存会命宫三方 |
| 加分 | 太阳庙旺；天梁庙旺；再会化科 |
| 破格 | 太阳落陷（阳梁失辉）；三方煞重（≥2颗四煞） |

出处：《紫微斗数全书·阳梁昌禄格》

### 5. 火贪格/铃贪格

贪狼遇火星/铃星同宫或三方会照，主突发横财、突如其来的机遇。古书云"贪狼遇火铃，必发横财"，但来得快去得也快，宜见好就收。

| 层次 | 条件 |
|------|------|
| 必须 | 贪狼与火星/铃星同宫或会照；贪狼会照命宫三方 |
| 加分 | 贪狼庙旺；贪狼化禄/化权 |
| 破格 | 贪狼宫又见羊陀（破横发之力）；贪狼遇空劫（财来财去） |

出处：《紫微斗数骨髓赋》

### 6. 武贪格

武曲贪狼会命，财星与桃花欲望星交辉，古书云"武贪不发少年人"——三十岁后方能厚积薄发。主中年以后大富大贵，财源由人脉、应酬、欲望管理而来，适合金融、投机、销售、娱乐业。

| 层次 | 条件 |
|------|------|
| 必须 | 武曲贪狼同宫（丑/未）或对宫拱照；会照命宫三方 |
| 加分 | 再遇火星/铃星（火贪/铃贪叠加）；武曲化禄 |
| 破格 | 武贪宫见羊陀；武贪宫遇空劫 |

出处：《紫微斗数骨髓赋》

### 7. 杀破狼

七杀、破军、贪狼三星会命，开创闯荡之命格。一生变动多、不甘平凡，宜创业、军警、业务、销售。中年后才能稳定守成，年轻时易因冲动失利。

| 层次 | 条件 |
|------|------|
| 必须 | 七杀、破军、贪狼三星齐入命宫三方四正 |
| 加分 | 三方有化禄或化权（动得有力）；辅弼同会（变动中得贵人） |
| 破格 | 煞星过重（≥3颗四煞，动而无成）；命坐空劫（动得辛苦） |

出处：《紫微斗数全书·杀破狼》

### 8. 机月同梁

天机太阴天同天梁四星齐入命迁财官，文质彬彬、聪慧善谋。最适合公职、学术、文艺、医疗、服务等需稳定累积的行业，不宜大冒险大投机。

| 层次 | 条件 |
|------|------|
| 必须 | 天机、太阴、天同、天梁四星齐入命宫三方四正 |
| 加分 | 再会昌曲；再会化科 |
| 破格 | 煞星过多（≥3颗四煞，机月同梁忌煞）；命宫坐煞 |

出处：《紫微斗数全书·机月同梁格》

## 中格

条件相对宽松，吉凶参半，需看加分与破格情况定夺。

### 9. 廉贞天相格

廉贞天相同宫，印绶格局，主秉公处事、清廉之名，宜任公职、行政管理、法务、企划。怕见擎羊化忌，则反主官非。

| 层次 | 条件 |
|------|------|
| 必须 | 廉贞天相同宫 |
| 加分 | 见禄存或廉贞化禄；左辅会照 |
| 破格 | 廉相宫坐擎羊（廉杀羊倾向）；廉贞化忌 |

出处：《紫微斗数全书》

### 10. 武曲七杀

武曲七杀同宫，将星配财星，主果决刚毅、理财能力强，适合金融、军警、创业。但忌见化忌煞星，否则凶险。一生奋斗、积财但操心。

| 层次 | 条件 |
|------|------|
| 必须 | 武曲七杀同宫 |
| 加分 | 武曲化权；武曲化禄 |
| 破格 | 武曲化忌（财劫之兆）；武杀宫煞星过多 |

出处：《紫微斗数全书》

### 11. 天同天梁格

天同天梁同宫，福星与荫星共会，主宽厚和善、乐于助人，宜医疗、教育、宗教、社会公益。但偏温和保守，难成大富大贵之局。

| 层次 | 条件 |
|------|------|
| 必须 | 天同天梁同宫 |
| 加分 | 文昌会照；天同化禄 |
| 破格 | 煞星同坐 |

出处：《紫微斗数全书》

### 12. 日月同宫

太阳太阴于丑/未宫同宫，阴阳平衡，文武兼备。主异性缘佳、事业顺遂、名声远播。未宫日月双美尤佳，丑宫力量较平。

| 层次 | 条件 |
|------|------|
| 必须 | 太阳太阴同入丑宫或未宫 |
| 加分 | 未宫日月同辉（古书云未宫日月双美）；昌曲会照 |
| 破格 | 日月宫煞星同坐 |

出处：《紫微斗数全书》

### 13. 日月夹命

太阳太阴分居命宫两侧夹照，光明磊落，一生贵人相助，事业蓬勃。男主官贵，女主旺夫兴家。日月须不落陷方为真夹。

| 层次 | 条件 |
|------|------|
| 必须 | 太阳太阴分居命宫前后两宫 |
| 加分 | 太阳庙旺；太阴庙旺 |
| 破格 | 日月落陷（夹命无光） |

出处：《紫微斗数全书·日月夹命》

### 14. 巨日同宫

巨门太阳同寅/申宫，太阳化解巨门暗曜，主以口才、传媒、外语、专业立业。寅宫为佳，申宫力减。怕巨门化忌则官非。

| 层次 | 条件 |
|------|------|
| 必须 | 巨门太阳同入寅宫或申宫 |
| 加分 | 寅宫太阳庙旺，巨门得日光化解是非；巨门化禄/化权（口才生财） |
| 破格 | 巨门化忌（口舌官非）；申宫太阳偏西，巨门暗曜更显 |

出处：《紫微斗数全书·巨日同宫》

### 15. 石中隐玉

巨门坐命子午，外表平凡而内蕴才学。早年默默无闻、中年方显贵气，宜走专业、研究、口才、传媒。需有禄权或文昌相助方能"凿石见玉"。

| 层次 | 条件 |
|------|------|
| 必须 | 巨门入命于子宫或午宫 |
| 加分 | 巨门化禄/化权；文昌会照（石中隐玉得明） |
| 破格 | 巨门化忌（玉藏深泥）；命坐煞星 |

出处：《紫微斗数骨髓赋·石中隐玉》

### 16. 明珠出海

命未空宫，对宫丑宫日月同辉拱照，号"明珠出海"。主出生平凡、后天努力出头，宜远赴他乡、学术研究或大公司高位，主大富大贵。

| 层次 | 条件 |
|------|------|
| 必须 | 命宫在未为空宫；对宫丑宫为太阳太阴同度 |
| 加分 | 再会昌曲；辅弼相助 |
| 破格 | 煞星会照（珠光黯淡，≥2颗四煞） |

出处：《紫微斗数全集·明珠出海》

### 17. 紫微入命

紫微独坐命宫，帝王之星，自尊心强、有领导魅力。但紫微最忌"在野孤君"——若无左右辅弼相会，反成孤高自傲、易招毁谤。

| 层次 | 条件 |
|------|------|
| 必须 | 紫微独坐命宫（无天府同坐） |
| 加分 | 左辅右弼同会；文昌文曲同会 |
| 破格 | 无辅弼（孤君无臣）；紫微遇空劫（古书最忌） |

出处：《紫微斗数全书》

## 恶格

禄存坐命，主一生衣食无忧、财禄稳定。性格保守，善积累，但羊陀夹禄须防小人。最宜配化禄、左辅右弼方为大格。禄存入身宫，主中年后财源稳定、得禄自享。倪师说「禄存入身，财气近身」——配偶或事业方向能带来稳定财禄。
