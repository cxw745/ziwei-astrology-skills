# 大限/流年硬约束规则

> 灵感来源：vedic-astro-skills 的 Dasha 硬约束机制（hard-constraint rules），适配紫微斗数大限/流年体系重写。

## 核心理念

大限/流年的正负面判定不是"感觉"，而是有**明确判定条件**的可计算判定。模型没有空间去"感觉"——数条件就行。

## 大限正面条件

满足≥2条 → 正面因素：

| 编号 | 条件 | 说明 |
|------|------|------|
| P1 | 大限宫干化禄入命宫/身宫/官禄宫/财帛宫 | 化禄入核心宫位，能量正面 |
| P2 | 大限主星庙旺（非落陷） | 主星状态好，执行力强 |
| P3 | 大限无化忌冲命宫/身宫 | 核心宫位不受忌冲 |
| P4 | 大限三方四正会吉星（左辅右弼/天魁天钺/化禄化权化科） | 有贵人助力 |
| P5 | 大限宫位为命盘强宫（命/财/官/迁） | 落在发力宫位 |

## 大限负面条件

满足任一即标注风险：

| 编号 | 条件 | 说明 |
|------|------|------|
| N1 | 大限宫干化忌入命宫/身宫 | 核心宫位受忌冲，压力信号 |
| N2 | 大限主星落陷+煞星同宫（擎羊/陀罗/火星/铃星/地空/地劫） | 主星无力且受煞 |
| N3 | 大限冲本命夫妻宫/官禄宫+化忌 | 关键宫位受冲带忌 |
| N4 | 大限宫位为命盘弱宫且无吉星会照 | 孤立无援 |
| N5 | 大限与流年化忌叠加（大限化忌+流年化忌同宫或对冲） | 双忌叠加，压力倍增 |

## 大限判定逻辑

```
正面≥2 且 负面=0 → 顺遂期
正面≥2 且 负面≥1 → 波折期
正面<2 且 负面≥1 → 困难期
正面=0 且 负面≥2 → 危机期
```

## 流年叠加规则

大限定基调，流年定节奏：

| 大限 | 流年 | 叠加判定 | 表述方式 |
|------|------|---------|---------|
| 顺遂期 | 正面 | 黄金年 | "该年大限流年双吉，是发力冲刺的好时机" |
| 顺遂期 | 负面 | 好事多磨 | "大限底子好，但该年有波折，是暂时的" |
| 波折期 | 正面 | 曙光年 | "大限整体波折，但该年有转机" |
| 波折期 | 负面 | 雪上加霜 | "大限流年双压，该年需格外谨慎" |
| 困难期 | 正面 | 透气年 | "大限困难中该年稍有缓解，但不可掉以轻心" |
| 困难期 | 负面 | 至暗年 | "大限流年双压，该年是困难期中的困难期" |
| 危机期 | 任何 | 高危年 | "大限已处危机，无论流年如何都需高度警惕" |

## 禁止的推导错误

以下5条直接打击5种圆场模式，每条都是硬性禁止：

### 1. 凶→好 的美化

```
❌ 大限化忌冲命宫 → "这是成长的考验"
✅ 大限化忌冲命宫 → "该大限在XX领域有压力/波折"
```

打击模式：把凶象包装成"功课""礼物""考验"。

### 2. 弱→强 的鸡汤

```
❌ 大限主星落陷+煞星 → "在逆境中锤炼自己"
✅ 大限主星落陷+煞星 → "该大限执行力受限，可能面临XX方面的压力"
```

打击模式：把弱象包装成"磨炼""锤炼""锻炼"。

### 3. 已知结果→调整判断 的确认偏误

```
❌ 命宫主星庙旺+吉星会照 → 因为用户说"我过得不好"就弱化
✅ 命宫主星庙旺+吉星会照 → "命宫格局好，困难可能来自大限/流年的阶段性影响"
```

打击模式：用户描述的负面经历影响对盘面正面信号的判断。

### 4. 凶→功课 的灵性包装

```
❌ 夫妻宫化忌+煞星 → "这是灵魂伴侣的考验"
✅ 夫妻宫化忌+煞星 → "感情执念深，早婚不利，建议晚婚"
```

打击模式：用灵性语言美化凶象（"灵魂功课""业力清理""深层转化"）。

### 5. 用户说惨→我也说惨 的讨好

```
❌ 大限化禄入财帛宫 → 因为用户说"那十年很穷"就判负面
✅ 大限化禄入财帛宫 → "该大限在财运方面有正面能量"
```

打击模式：用户描述的负面经历覆盖盘面的正面信号。

## 大限回顾必须双向

分析过去的大限时，同一个大限必须同时列出可能的正面和负面表现：

```
❌ 知道用户2015-2024年很苦 → 只写该大限的负面表现
✅ 该大限可能的表现：
   正面：XX领域有机会/突破
   负面：XX领域有压力/波折
   实际表现取决于个人选择和行运触发
```

## 格局激活验证

格局不是静态标签，需要验证何时激活、能否兑现：

### 三层验证

| 层级 | 验证内容 | 说明 |
|------|---------|------|
| 第1层 | 本命盘格局是否成立 | 这是"承诺" |
| 第2层 | 哪个大限/流年激活这个格局 | 这是"时机" |
| 第3层 | 激活时相关星曜的状态如何 | 这是"品质" |

### 兑现率估算

```
格局成立 + 激活大限主星庙旺 + 无煞星冲 → 兑现率70-90%
格局成立 + 激活大限主星平 + 有吉星会照 → 兑现率40-60%
格局成立 + 激活大限主星落陷 + 煞星同宫 → 兑现率10-30%
格局成立 + 未找到激活大限 → "格局存在但尚未激活，需等待时机"
```

### 表述规范

```
❌ "你有君臣庆会格，大富大贵！"
✅ "君臣庆会格成立（承诺），第4大限（32-41岁）紫微化权激活（时机），
   激活时紫微庙旺无煞冲（品质好），兑现率约70-80%。
   但在第2-3大限此格局尚未激活，不可过早期待。"
```
