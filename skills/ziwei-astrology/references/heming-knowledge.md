## 双宫联参原则

**核心口诀：「看婚姻，光看夫妻宫，大错特错，一定要同时看福德宫。」**

- 夫妻宫：看配偶的星性、外形、性格、互动模式
- 福德宫：代表夫妻深层感情、婚姻能否长久
- 倪师案例："有人夫妻宫很好，福德宫很烂，散！夫妻要散。"

合盘时必须同时分析双方的：命宫 + 夫妻宫 + 福德宫

## 天作之合判断

**最高级匹配（天作之合）**：
- 甲方夫妻宫主星 = 乙方命宫主星
- 乙方夫妻宫主星 = 甲方命宫主星

**次级良配**：
- 一方夫妻宫主星 = 对方命宫主星（单向对应）
- 双方命宫星性五行相生
- 双方大限同走旺运

**凶兆组合**：
- 双方互相化忌冲对方命宫
- 一方化忌飞入另一方夫妻宫
- 双方夫妻宫皆有重煞无吉星

## 合盘五步法

1. 评估双方命格基础（命宫+身宫+福德宫星性搭配）
2. 夫妻宫互参（双方夫妻宫主星是否对应对方命宫/三合方星）
3. 太阳太阴星象分析（女命太阳=丈夫，男命太阴=妻子）
4. 四化飞化互参（甲方四化星落在乙方命盘哪个宫位）
5. 大限同步分析（双方当前大限是否同走旺运）

## 婚期判断三层法

**第一层：本命盘格局**
- 夫妻宫无煞：宜早婚
- 夫妻宫有煞无吉：宜晚婚（男30以上，女27以上）
- 武曲、廉贞、七杀、破军在夫妻宫：一律建议晚婚

**第二层：大限**
- 大限夫妻宫吉星多：该十年有结婚机会
- 大限夫妻宫化忌：该十年感情受阻

**第三层：流年**
- 红鸾、天喜入命宫或夫妻宫：该年婚恋有动
- 流年宫位落到夫妻宫：该年婚姻是重点

## 友情合盘原理与宫位体系

### 核心原理

紫微斗数中，判断两人友情缘分的关键宫位与婚配完全不同：

| 维度 | 婚配合盘 | 友情合盘 |
|------|---------|---------|
| 核心宫位 | 夫妻宫 + 福德宫 | 兄弟宫 + 仆役宫 |
| 辅助宫位 | 太阳太阴 | 迁移宫（社交）+ 福德宫（精神契合） |
| 判断标准 | 夫妻宫主星是否对应对方命宫 | 对方命宫主星落入自己哪个宫位 |
| 四化侧重 | 化禄=正缘，化忌=欠债 | 化禄=有益，化忌=消耗 |
| 评级体系 | 天作之合/良配/互补/需经营/高风险 | 莫逆之交/知己/益友/泛交/损友 |

### 双宫联参原则（友情版）

**核心口诀：「看友情，兄弟宫看深交，仆役宫看广交，两者联参方全。」**

- **兄弟宫**：代表亲密同辈关系——闺蜜、兄弟、像家人一样的朋友。兄弟宫好=深交有靠，兄弟宫差=亲密关系中易有摩擦
- **仆役宫**（交友宫）：代表社交圈、普通朋友、下属、合作伙伴。仆役宫好=广交有缘，仆役宫差=社交中易遇消耗你的人
- 倪师断语："巨门在朋友宫，跟朋友合伙会朋友变仇人。" [来源: ziwei-doushu/lib/nihai/tianji.ts]

### 对方命宫落入法（友情合盘核心方法）

友情合盘最关键的分析方法是：**看对方的命宫主星落入你命盘的哪个宫位**。这决定了对方在你生命中扮演的角色：

| 对方命宫落入你的宫位 | 友情含义 |
|---------------------|---------|
| 命宫 | 灵魂镜像型朋友，像看到另一个自己 |
| 兄弟宫 | 天生"自己人"，像家人一样的朋友（最强友情信号） |
| 夫妻宫 | 有吸引力但容易越界，需注意友情/爱情边界 |
| 子女宫 | 保护欲或被保护的关系，有照顾与被照顾的动态 |
| 财帛宫 | 财务上有交集的朋友，可能一起赚钱或一起花钱 |
| 疾厄宫 | 对方能触发你内心深处的脆弱或疗愈 |
| 迁移宫 | 在外地/新环境中认识的朋友，社交场合缘分深 |
| 仆役宫 | 普通社交朋友，关系较浅但可能有合作价值 |
| 官禄宫 | 事业上的贵人或搭档，友情以事业为纽带 |
| 田宅宫 | 家庭/居住环境有关的朋友，可能是邻居或室友 |
| 福德宫 | 精神世界高度契合，能聊到灵魂深处的知己 |
| 父母宫 | 对方像长辈或导师，有指导与被指导的关系 |

**双向落入**：同时看甲方命宫落入乙方哪个宫位 + 乙方命宫落入甲方哪个宫位。双向落入的宫位组合决定友情的基本结构。

### 左辅右弼在友情中的意义

左辅右弼是紫微斗数最强的两颗贵人星，在友情分析中极为重要：

| 星曜 | 友情含义 |
|------|---------|
| 左辅在兄弟宫 | 兄弟姐妹或亲密朋友中有男性贵人，朋友忠诚可靠 |
| 右弼在兄弟宫 | 兄弟姐妹或亲密朋友中有女性贵人，朋友温柔体贴 |
| 左辅右弼同在兄弟宫 | 最强友情贵人配置，一生不缺真心朋友 |
| 左辅右弼在仆役宫 | 社交圈贵人多，但关系不如兄弟宫深 |
| 左辅右弼在命宫 | 天生人缘好，走到哪都有人帮 |

倪师断语："左辅右弼在兄弟宫，兄弟姐妹得力，如同贵人。这种人的朋友也像家人一样可靠，一生不会孤单。" [来源: ziwei-doushu/lib/nihai/tianji.ts]

## 友情合盘六步法

与婚配合盘五步法平行，但宫位侧重和分析逻辑完全不同：

### 第一步：评估双方命格基础

分析双方命宫+身宫的星性搭配，判断两人性格是否合拍：

| 命格组合 | 友情契合度 | 说明 |
|---------|----------|------|
| 同格局型（如双方都是杀破狼） | ★★★★ | 节奏相似，互相理解变动与不安 |
| 互补型（杀破狼+机月同梁） | ★★★★ | 动静互补，一个冲一个稳 |
| 同刚型（七杀+七杀/武曲+武曲） | ★★ | 两虎相争，容易较劲 |
| 同柔型（天同+天同/天梁+天梁） | ★★★ | 和平相处但缺乏火花 |

### 第二步：对方命宫落入法（核心步骤）

看对方命宫主星落入自己命盘的哪个宫位——这决定对方在你生命中的角色定位。

**最强友情信号**：对方命宫落入你的兄弟宫 = 天生"自己人"
**需警惕信号**：对方命宫落入你的夫妻宫 = 友情容易越界

### 第三步：兄弟宫+仆役宫互参

- 甲方兄弟宫主星 vs 乙方兄弟宫主星：深交模式是否兼容
- 甲方仆役宫主星 vs 乙方仆役宫主星：社交风格是否合拍
- 甲方兄弟宫/仆役宫中的吉星（左辅右弼天魁天钺）是否与乙方命宫形成呼应

### 第四步：四化飞化互参（友情侧重）

与婚配合盘的四化互参逻辑相同，但解读侧重不同：

| 四化 | 婚配解读 | 友情解读 |
|------|---------|---------|
| 化禄 | 正缘、真爱 | 对你有益的朋友，相处让你更好 |
| 化权 | 主动争取、主导 | 关系中有主导方，一方更强势 |
| 化科 | 和谐相处 | 互相尊重欣赏，精神层面契合 |
| 化忌 | 欠债、逆缘 | 消耗型关系，对方带来麻烦或执念 |

**友情化忌的特殊性**：化忌在友情中不像婚配那样一定是坏事——化忌也可能表现为"放不下的朋友""总惦记的人"，有时反而是最深的羁绊。但如果双方互化忌冲命宫，则确实是消耗型关系。

### 第五步：贵人星与煞星分析

- 左辅右弼：友情中的贵人星，出现在兄弟宫/仆役宫最强
- 天魁天钺：偶遇型贵人，朋友在关键时刻帮你一把
- 擎羊陀罗：友情中的摩擦源，擎羊=明争，陀罗=暗耗
- 火星铃星：友情中的冲突源，火星=爆发式吵架，铃星=冷战
- 地空地劫：友情中的疏离感，聚少离多或关系难以深入

### 第六步：大限同步分析

分析双方当前大限是否同走旺运：
- 同走旺运：友情升温期，容易成为密友
- 一旺一衰：关系可能失衡，一方依赖另一方
- 同走衰运：友情考验期，需要互相支撑

## 友情合盘与婚配合盘核心差异

| 维度 | 婚配合盘（\match） | 友情合盘（\friend） |

| 关键方法 | 夫妻宫互参+太阳太阴 | 对方命宫落入法+兄弟仆役互参 |
