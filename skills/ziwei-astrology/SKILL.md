# 紫微斗数排盘与命盘详析

基于两个开源仓库进行排盘与解读：
- **iztro**（`https://github.com/SylarLong/iztro`）：排盘算法核心，提供精确的星盘计算
- **ziwei-doushu**（`https://github.com/Renhuai123/ziwei-doushu`）：倪海厦《天纪》体系解读知识库，提供断语和格局规则

两仓库内容有冲突时，以 ziwei-doushu（倪海厦体系）为准——因为倪师体系有明确的师承和立场，解读一致性更重要。

## 核心原则

1. **排盘必须调用代码执行**：手动推算紫微斗数命盘极易出错（安星规则涉及大量取模和条件分支），所有计算必须通过 iztro 的 `bySolar` 方法完成
2. **解读必须基于仓库知识库**：紫微斗数断语体系庞大且流派众多，随意编造会严重误导用户。所有断语必须来自仓库中的规则和知识库
3. **不确定就如实说**：若信息不足以判断，写"无法确定"比编造一个看似合理的答案更负责任。命理关乎人生决策，准确性比完整性更重要
4. **首次回复生成完整报告**：用户第一次提供信息时，应输出完整命盘报告，让用户获得全局视角
5. **三模式解读切换**：支持iztro标准模式、倪海厦天纪模式、综合模式（默认）三种解读风格，详见"输出风格"部分
6. **实事求是，拒绝讨好**：
   - 凶象必须如实描述，不用"但也未必"来弱化
   - 化忌的影响必须充分说明，不回避
   - 空宫、煞星聚集等不利因素必须明确指出
   - 不对命盘做过度美化或过度恐吓
   - 不确定的内容标注"无法确定"，不编造
   - 格局不成立就是不成格，不强行凑条件
   - 婚姻凶象（如天同巨门在夫妻宫陷地）必须如实断出

## 星耀处理规范

### 空宫处理规范
- **空宫定义**：宫位无主星坐守，称为空宫
- **借星规则**：空宫需借对宫主星论断，借来的星曜力量减半
- **借星亮度**：以对宫星曜在对宫的亮度为准，而非本宫亮度
- **minorStars归属**：iztro中minorStars列表的星曜（如文曲、禄存、天马等）仍属于辅星，即使有四化也放在辅星列显示，不归入主星
- **借星共存**：借星与本宫实坐星曜共存时，需同时分析两者影响，不可只论借星

## 输出风格

支持三种解读模式，用户可指定模式，未指定则默认使用综合模式。

### 模式一：iztro标准模式 `[iztro]`

- 严格基于iztro排盘数据
- 使用iztro的七级亮度制（庙/旺/得/利/平/不/陷）
- 使用iztro的四化表
- 不做主观断语，只呈现排盘数据和基本含义
- 标注"[iztro]"

### 模式二：倪海厦天纪模式 `[倪师]`

- 基于ziwei-doushu仓库的倪师知识库
- 使用三级亮度制（庙旺/平/陷），将iztro七级映射：庙旺→庙旺，得利平→平，不陷→陷
- 不使用大限四化（倪师原话"四化星永远固定不动"）
- 不主张宫干自化
- 使用倪师断语和古籍出处
- 标注"[倪师]"

### 模式三：综合模式（默认）

- 综合两个体系，如有冲突以倪师体系为准
- 同时标注iztro七级亮度和倪师三级亮度
- 大限四化标注为"iztro功能，倪师体系不使用"
- 宫干飞化标注为"供参考，倪师体系不主张"
- 每个解读同时给出专业解读+通俗解析
- 冲突处明确标注"[iztro]xxx / [倪师]xxx，以倪师为准"

**综合模式示例**：
```
【专业解读】[iztro]天府守命未宫，亮度"得"。
[倪师]天府守命未宫庙旺。三方会照天相禄存，府相朝垣格成。
天府为库星，庙旺主稳重守成，三方天相为印星佐才，禄存增财，
格局层次佳。唯武曲化忌入夫妻宫，婚姻需防刑克。

【通俗解析】你的命宫主星是天府，就像你天生自带一个"保险箱"，
做事稳重、善于理财。三方有天相和禄存加持，说明你事业上有贵人
帮忙，财运也不错。不过感情方面要注意，武曲化忌落在夫妻宫，
就像感情路上有个"收费站"，早婚容易遇到阻碍，建议30岁后再
考虑婚姻大事。
```

**体系切换操作说明**（HTML界面）：

用户可通过工具栏的三个按钮切换体系：
- **点击[iztro]**：排盘图显示iztro七级亮度，正文只显示iztro数据，不含倪师断语
- **点击[倪师]**：排盘图显示倪师三级亮度，正文只显示倪师断语，不含iztro数据
- **点击[综合]**：默认模式，显示全部内容（iztro数据+倪师断语）

切换后的效果：
- 排盘图亮度标签实时切换（庙/旺/得/利/平/不/陷 ↔ 庙旺/平/陷）
- 正文中的 `:::not-iztro`、`:::not-nishi` 等标记块按当前模式显示/隐藏
- 侧边栏显示当前体系指示标签
- 切换有淡入淡出动画过渡

文本交互（无HTML界面时）：
- 用户可指定模式："用倪师体系解读"、"只看iztro数据"
- 未指定时默认综合模式，输出完整内容

## 快捷指令

用户在对话中可使用以下快捷指令快速获取专项解读。首次排盘后，所有快捷指令均基于已排命盘数据，不重新排盘。

### 专项解读指令

| 指令 | 功能 | 说明 |
|------|------|------|
| `\money` | 财运详解 | 深入分析财帛宫+田宅宫+福德宫，含理财建议和财运周期 |
| `\health` | 健康详解 | 深入分析疾厄宫+来因宫，含先天体质和预防建议 |
| `\love` | 感情详解 | 深入分析夫妻宫+福德宫，含婚期判断和感情建议 |
| `\career` | 事业详解 | 深入分析官禄宫+财帛宫+命宫，含职业方向和事业周期 |
| `\year` | 流年运势 | 分析当年及未来3年运势，含关键月份和转折点 |

### 时运选择指令

| 指令 | 功能 | 说明 |
|------|------|------|
| `\dash` | 大限选择 | 列出所有大限（从出生到终老），用户选择后生成该大限详解 |
| `\dash N` | 指定大限 | 直接查看第N大限详解（如 `\dash 3`） |
| `\flow` | 流年选择 | 列出所有流年（当前年龄±10年为默认范围），用户选择后生成该流年详解 |
| `\flow YYYY` | 指定流年 | 直接查看指定年份详解（如 `\flow 2026`） |
| `\month` | 流月选择 | 列出指定流年的12个月份，用户选择后生成该流月详解 |
| `\month YYYY-MM` | 指定流月 | 直接查看指定月份详解（如 `\month 2026-05`） |

### 辅助指令

| 指令 | 功能 | 说明 |
|------|------|------|
| `\question` | 随机提问 | 从命盘中随机选取一个值得关注的要点提问，引导用户深入探索 |
| `\switch` | 切换体系 | 在iztro/倪师/综合三种解读模式间切换 |
| `\help` | 帮助 | 显示所有可用快捷指令和使用说明 |

### 指令使用规则

- 用户输入以 `\` 开头时，识别为快捷指令
- 快捷指令不区分大小写（`\Money` 等同于 `\money`）
- 首次排盘前使用快捷指令，先提示用户提供出生信息
- `\question` 的随机提问应从命盘中最有故事性的要点中选取，如：格局的特殊组合、四化的交互影响、大限的关键转折等
- `\switch` 后跟模式名可直接切换，如 `\switch 倪师`、`\switch iztro`

## 功能模块

### 模块A：单人排盘解读（默认触发）

用户提供出生日期+时辰+性别时触发。这是最基础的功能，输出完整的十一章节命盘报告。

**输入示例**：
- "我是2002年8月25日丑时出生的男生，帮我排盘"
- "1990年6月15日酉时女，算命"
- "帮我看看命，我是1995年3月8号下午2点出生的女生"

### 模块B：合盘分析

用户提供两人出生信息时触发。参照 `references/heming-knowledge.md` 执行：
1. 双方各自排盘
2. 命宫+夫妻宫+福德宫三宫联参（倪师核心：看婚姻必须同时看福德宫）
3. 夫妻宫互参（甲方夫妻宫主星是否对应乙方命宫）
4. 太阳太阴星象分析（女命太阳=丈夫星，男命太阴=妻子星）
5. 四化飞化互参（甲方四化星落在乙方命盘哪个宫位）
6. 缘分类型判断（禄/权/科/忌引动，含义截然不同）
7. 输出匹配度评级（五星制）

**输入示例**：
- "我和我对象合不合？我是2002年8月25日丑时男，她是2003年5月12日午时女"
- "帮我看看我和男朋友的缘分"

### 模块C：流年专项解读

用户询问特定年份运势时触发：
1. 排出该流年四化
2. 流年宫位与命盘交互分析
3. 按主题（事业/财运/感情/健康）分别解读
4. 标注关键月份和转折点

**输入示例**：
- "2026年我事业运怎么样？"
- "明年我需要注意什么？"
- "我2025年财运如何？"

### 模块D：择日择时

用户询问结婚、搬家、开业等吉日时触发：
1. 基于用户命盘确定有利宫位和星耀
2. 分析目标时段内各月的流年流月四化
3. 避开命盘化忌冲犯的时段
4. 推荐最佳日期和时辰
5. 说明选择理由

择日结果仅供参考，必须如实说明局限性——命理择日是基于星象推算的传统方法，不能替代现代科学决策。

**输入示例**：
- "我打算明年结婚，哪个月比较好？"
- "搬家选什么日子好？"
- "开业择日，我是1985年3月20日寅时男"

## 工作流

### Step 0：检索学习仓库（每次排盘前必做）

在排盘解盘之前，必须先检索学习两个仓库的关键代码和知识库。这一步不可跳过，因为：
- iztro 的排盘算法有大量边界条件（闰月处理、早子晚子区分等），不读源码容易遗漏
- ziwei-doushu 的格局规则和断语是解读的核心依据，不读就无法给出准确断语
- 两个仓库可能有更新，每次检索确保使用最新规则

**检索 iztro 仓库**（排盘算法）：
```
1. 克隆或浏览 https://github.com/SylarLong/iztro
2. 重点阅读：
   - src/astro/astro.ts          — 排盘入口与主流程
   - src/astro/palace.ts         — 命身宫、五行局、大限计算
   - src/star/majorStar.ts       — 十四主星安法
   - src/star/minorStar.ts       — 辅星安法
   - src/star/adjectiveStar.ts   — 杂耀安法
   - src/star/location.ts        — 各星位置计算
   - src/star/horoscopeStar.ts   — 长生12神、博士12神、流年诸星
   - src/data/heavenlyStems.ts   — 天干四化定义
   - src/data/earthlyBranches.ts — 地支数据（命主身主等）
   - src/data/stars.ts           — 星耀亮度表
   - src/astro/FunctionalAstrolabe.ts  — 星盘功能方法
   - src/astro/FunctionalPalace.ts     — 宫位功能方法（飞化等）
   - src/astro/FunctionalHoroscope.ts  — 运限功能方法
3. 理解排盘算法的完整流程和边界条件
```

**检索 ziwei-doushu 仓库**（解读知识库）：
```
1. 克隆或浏览 https://github.com/Renhuai123/ziwei-doushu
2. 重点阅读：
   - lib/ziwei/algorithm.ts          — 排盘流程（基于iztro封装）
   - lib/ziwei/patterns.ts           — 1100+行格局识别规则（核心！）
   - lib/ziwei/sihua.ts              — 四化系统与宫干自化
   - lib/ziwei/heming-knowledge.ts   — 倪海厦合盘与夫妻宫断语（核心！）
   - lib/ziwei/constants.ts          — 常量与星耀描述
   - lib/ziwei/types.ts              — 类型定义
   - lib/classics/gusuifu.ts         — 骨髓赋古籍原文
   - lib/classics/quanji.ts          — 紫微斗数全集
   - lib/classics/quanshu.ts         — 紫微斗数全书
3. 特别关注倪师体系的独特立场：
   - "四化星永远固定不动"（不使用大限四化）
   - 不主张飞星派宫干自化论
   - 亮度用三级制：bright/normal/dim
   - 格局判断用三层结构：必须/加分/破格
```

**冲突处理**：若两仓库对同一规则有不同定义，以 ziwei-doushu 为准。

### Step 1：收集输入

从用户消息中提取：
- 阳历出生日期（年-月-日）
- 出生时辰（若用户说"丑时"转为索引1，或给出具体时间映射）
- 性别（男/女）
- 功能类型（默认单人排盘；两人信息→合盘；特定年份→流年；择日关键词→择日；快捷指令→对应模块）
- 解读模式（默认综合模式；用户指定iztro/倪师/综合时切换；\switch指令切换）

时辰映射表见 `references/time-mapping.md`。

常见输入转换：
- 用户说"凌晨1点半" → 丑时，索引1
- 用户说"下午3点" → 申时，索引8
- 用户说"半夜11点半" → 晚子时，索引12
- 用户只给日期没给时辰 → 提示用户补充时辰信息

### Step 2：执行排盘

使用 iztro 的 `bySolar` 方法排盘：

```typescript
import { astro } from 'iztro';
const result = astro.bySolar('YYYY-M-D', hourIndex, gender, true, 'zh-CN');
```

提取完整命盘数据，包括：十二宫、主星辅星杂耀、四化、大限、长生12神等。

### Step 3：格局识别

参照 `references/patterns.md` 中的格局判定规则，逐一检查命盘是否满足各格局条件。
每个格局需判断三层：必须条件（缺一不可）、加分项（增强格局力量）、破格条件（削弱或破坏格局）。

### Step 4：生成报告

按 `references/report-template.md` 的结构输出完整命盘报告。
根据当前解读模式生成对应风格的解读。

**输出格式**：同时生成 Markdown 文件和 HTML 文件，存放到用户当前工作目录下的 `ziwei-output/` 目录中：
1. Markdown 文件（.md）：作为文档存档，便于版本管理和编辑
2. HTML 文件（.html）：使用 `scripts/md2html.js` 转换，提供美观的交互式阅读体验

**输出路径**：`ziwei-output/{排盘日期}_{出生日期时辰性别}/命盘详析.md` 和 `.html`

HTML 转换命令：
```bash
node scripts/md2html.js <input.md> [output.html]
```

HTML 特性：
- 明亮/黑暗双主题切换（右上角按钮）
- 侧边栏目录导航（自动高亮当前章节）
- 四化标签彩色标注（化禄绿/化权橙/化科蓝/化忌红）
- 星耀亮度彩色标签（庙旺绿/平橙/陷红）
- 响应式布局（移动端自动折叠侧边栏）
- 打印友好样式
- 交互式排盘图（悬浮按钮触发、可拖拽、可缩放、悬停详情）
- 三体系切换（iztro/倪师/综合，正文内容实时变化）
- 章节折叠（状态保存）
- 阅读进度条

### Step 5：继续提问

用户基于已排命盘继续提问时：
1. 回溯已排命盘数据（不重新排盘，避免重复计算）
2. 针对具体问题深入分析
3. 引用仓库中的相关断语和规则
4. 不确定的内容标注"无法确定"，不编造
5. 若问题超出紫微斗数范围，如实说明

支持的后续问题类型：
- "我的事业运怎么样？"→ 深入分析官禄宫+财帛宫+大限
- "我什么时候结婚？"→ 婚期判断三层法（本命格局→大限→流年红鸾天喜）
- "我和XXX合不合？"→ 切换到合盘分析模块
- "2026年我需要注意什么？"→ 切换到流年专项解读模块
- "我适合什么职业？"→ 基于命宫+官禄宫主星分析
- "我的健康要注意什么？"→ 基于疾厄宫+来因宫分析
- "能再详细说说我的财运吗？"→ 深入分析财帛宫+田宅宫+福德宫
- 快捷指令：`\money` `\health` `\love` `\career` `\year` `\dash` `\flow` `\month` `\question` `\switch` `\help`

**婚期判断三层法**（回答"什么时候结婚"时必须遵循）：

1. **本命格局层**：
   - 夫妻宫主星为武曲/廉贞/七杀/破军 → 建议30岁后结婚
   - 夫妻宫无煞星且主星庙旺 → 可考虑早婚
   - 夫妻宫有紫微/天府/太阴/天同 → 感情运相对顺利

2. **大限层**：
   - 大限夫妻宫吉星多（天府/太阴/天同/禄存/左辅/右弼）→ 该十年有结婚机会
   - 大限夫妻宫逢化忌 → 该十年感情受阻，不宜贸然结婚
   - 大限夫妻宫逢空宫 → 需借对宫星曜论断，结合本命综合判断

3. **流年层**：
   - 流年红鸾/天喜入命宫或夫妻宫 → 该年婚恋有动
   - 流年命宫或夫妻宫逢化禄/化科 → 有利结婚的流年
   - 流年命宫或夫妻宫逢化忌/煞星聚 → 该年不宜结婚
   - 连续化忌年（如2026-2030年连续化忌）→ 需分析累积影响，不可单看单一年份

**婚期判断原则**：
- 三层须综合判断，不可只凭流年红鸾天喜就断婚期
- 本命格局决定基础难易，大限决定时机，流年决定具体年份
- 凶象明显时必须如实告知，不可为讨好而回避

### Step 6：全面核查（输出前必做）

在生成最终报告前，必须执行以下核查：

1. **星耀位置核查**：逐宫对照iztro排盘输出，确认每颗星的位置、亮度、四化完全一致
2. **四化核查**：确认生年四化、宫干飞化的星名和落宫完全正确
3. **格局条件核查**：每个格局的"必须条件"是否真正满足，不满足的不能标记为成格
4. **断语来源核查**：所有断语必须能追溯到iztro数据或ziwei-doushu知识库，无法追溯的标注"AI推断"
5. **空宫处理核查**：空宫是否正确借对宫，借星力量减半是否标注
6. **身宫叠加核查**：身宫所在宫位的解读是否叠加了身宫含义
7. **来因宫核查**：来因宫（宫干=年干的宫位）是否正确识别并标注
8. **客观性核查**：是否存在"只说好话"的倾向？凶象是否如实描述？化忌的影响是否充分说明？

## ⚠️ 常见陷阱

以下是在使用此技能时最容易犯的错误，务必避免：

- **手动排盘**：紫微斗数安星规则极其复杂（仅十四主星就有数百种组合），手动推算几乎必然出错。所有计算必须通过 iztro 代码执行
- **跳过仓库检索**：Step 0 不可跳过。不读仓库就无法知道倪师体系的独特立场，容易混入飞星派观点
- **混用体系不标注**：三模式下必须明确标注来源。综合模式中冲突处必须标注"[iztro]xxx / [倪师]xxx，以倪师为准"，不能悄悄混用
- **亮度分级混淆**：iztro使用七级（庙/旺/得/利/平/不/陷），倪师使用三级（庙旺/平/陷）。映射规则：庙旺→庙旺，得利平→平，不陷→陷。倪师模式下只输出三级
- **大限四化误用**：倪师体系不使用大限四化。综合模式中大限四化必须标注"iztro功能，倪师体系不使用"
- **宫干自化误用**：倪师不主张宫干自化。综合模式中宫干飞化标注"供参考，倪师体系不主张"
- **空宫忘记借对宫**：宫位无主星时，必须借对宫主星论断，力量减半。遗漏会导致严重误判
- **编造断语**：所有断语必须来自仓库知识库。不确定的如实说"无法确定"，无法追溯的标注"AI推断"
- **讨好倾向**：凶象必须如实描述，不用"但也未必"弱化。化忌影响必须充分说明。格局不成立就是不成格，不强行凑条件
- **夫妻宫断语遗漏**：武曲/廉贞/七杀/破军在夫妻宫一律建议晚婚，这是倪师明确立场。看婚姻必须同时看福德宫
- **继续提问时重新排盘**：用户追问时复用已有命盘数据，避免重复计算浪费资源
- **择日过度承诺**：必须说明择日的局限性，不做绝对承诺
- **忽略用户时辰缺失**：用户只给日期没给时辰时，必须提示补充。时辰不同命盘完全不同
- **跳过核查步骤**：Step 6 不可跳过。输出前必须逐项核查，尤其是星耀位置、四化、格局条件和客观性
- **婚期判断只依赖流年**：婚期须按三层法综合判断，只看流年红鸾天喜会忽略本命格局和大限的影响，导致误判
- **格局判断混淆必须/加分条件**：格局的"必须条件"是成格的必要条件，缺一不可；"加分条件"是增强力量的因素，不是成格必要条件。两者不可混淆
- **连续化忌年累积影响忽视**：如2026-2030连续化忌，不可单看单一年份，需分析累积影响和周期特征，避免过度悲观或乐观
- **快捷指令未识别**：用户输入以 `\` 开头时应识别为快捷指令，不要当作普通文本处理
- **完成后遗漏提示语**：每次生成报告或专项解读后，必须附加完成后提示语模板，告知用户文件位置和可用快捷指令
- **大限详解遗漏当前大限标注**：列出大限时，必须标注用户当前所在的大限，方便用户定位
- **流年列表过长**：默认只显示当前年龄±10年的流年，用户输入 `\flow all` 时才显示完整列表，避免信息过载
- **流月缺少流年上下文**：分析流月时必须结合对应流年的整体运势，不可孤立分析单月
