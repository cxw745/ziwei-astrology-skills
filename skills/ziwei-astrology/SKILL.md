# 紫微斗数排盘与命盘详析

基于两个开源仓库排盘与解读：
- **iztro**（`https://github.com/SylarLong/iztro`）：排盘算法核心
- **ziwei-doushu**（`https://github.com/Renhuai123/ziwei-doushu`）：倪海厦《天纪》体系知识库

冲突时以 ziwei-doushu（倪海厦体系）为准。

## 核心原则

1. **排盘必须调用代码**：手动推算极易出错，所有计算必须通过 iztro 的 `bySolar` 方法
2. **解读必须基于知识库**：所有断语必须来自 references 文件，不确定的标注"无法确定"
3. **实事求是，拒绝讨好**：凶象如实描述，不弱化化忌影响，不强行凑格局
4. **三模式解读**：iztro标准 / 倪海厦天纪 / 综合（默认），冲突以倪师为准
5. **双层输出**：专业解读 + 通俗解析
6. **首次输出完整报告**：用户第一次提供信息时输出完整命盘报告

## 星耀处理规范

- **空宫**：借对宫主星论断，力量减半，借星亮度以对宫为准
- **minorStars归属**：文曲、禄存、天马等属辅星，即使有四化也放辅星列
- **借星共存**：借星与本宫实坐星曜共存时需同时分析

## 三模式解读

| 模式 | 数据来源 | 亮度 | 大限四化 |
|------|---------|------|---------|
| [iztro] | iztro数据 | 七级 | 使用 |
| [倪师] | 倪师知识库 | 三级（庙旺/平/陷） | 不使用 |
| 综合（默认） | 两体系综合 | 双标注 | 标注差异 |

亮度映射：庙旺→庙旺，得利平→平，不陷→陷

综合模式冲突处标注"[iztro]xxx / [倪师]xxx，以倪师为准"。

HTML界面体系切换：工具栏按钮或键盘1/2/3切换，正文内容实时变化。

## 快捷指令

| 指令 | 功能 | 指令 | 功能 |
|------|------|------|------|
| `\money` | 财运详解 | `\health` | 健康详解 |
| `\love` | 感情详解 | `\career` | 事业详解 |
| `\year` | 流年运势 | `\question` | 随机提问 |
| `\dash` | 大限选择 | `\dash N` | 第N大限详解 |
| `\flow` | 流年选择 | `\flow YYYY` | 指定年详解 |
| `\month` | 流月选择 | `\month YYYY-MM` | 指定月详解 |

- 首次排盘前使用快捷指令，先提示用户提供出生信息
- `\dash` 列出所有大限并标注当前所在大限
- `\flow` 默认显示当前年龄±10年，`\flow all` 显示完整列表
- `\month` 需先确定流年（默认当年）
- 详细指引见 `references/shortcuts.md`

## 输出文件规范

**重要**：所有输出保存在用户工作目录下的 `ziwei-output/`，不写入 skills 目录。

```
ziwei-output/{日期}_{出生信息}/
├── 命盘详析.md / .html
├── {专项解读}.md / .html
├── 大限/第N大限_{年龄}.md / .html
├── 流年/{YYYY}年{干支}.md / .html
└── 流月/{YYYY}年{MM}月.md / .html
```

所有专项解读同时生成 .md 和 .html。HTML 转换命令：
```bash
node scripts/md2html.js <input.md> [output.html]
```

完成后必须附加提示语，告知文件位置和可用快捷指令。模板见 `references/report-template.md`。

## 功能模块

| 模块 | 触发条件 | 输出 |
|------|---------|------|
| 单人排盘 | 出生日期+时辰+性别 | 完整十一章节报告 |
| 合盘分析 | 两人出生信息 | 五步法+五星匹配度 |

## 工作流

### Step 1：收集输入

提取：阳历日期、时辰（→索引）、性别、功能类型、解读模式。

时辰映射见 `references/time-mapping.md`。用户只给日期没给时辰时必须提示补充。

### Step 2：执行排盘

```typescript
import { astro } from 'iztro';
const result = astro.bySolar('YYYY-M-D', hourIndex, gender, true, 'zh-CN');
```

### Step 3：格局识别

参照 `references/patterns.md`，每个格局判断三层：必须条件（缺一不可）、加分项、破格条件。

### Step 4：生成报告

按 `references/report-template.md` 结构输出，根据解读模式生成对应风格。

### Step 5：继续提问

复用已排命盘数据，不重新排盘。婚期判断必须遵循三层法（本命→大限→流年），详见 `references/report-template.md`。

### Step 6：核查（输出前必做）

1. 星耀位置与iztro排盘一致
2. 四化星名和落宫正确
3. 格局条件真正满足
4. 断语可追溯至references
5. 空宫正确借对宫
6. 身宫叠加正确
7. 来因宫正确
8. 无讨好倾向

## ⚠️ 常见陷阱

- **手动排盘**：必须通过 iztro 代码执行，手动推算几乎必然出错
- **混用体系不标注**：冲突处必须标注来源，不能悄悄混用
- **亮度混淆**：iztro七级 vs 倪师三级，映射：庙旺→庙旺，得利平→平，不陷→陷
- **大限四化误用**：倪师体系不使用，综合模式必须标注
- **宫干自化误用**：倪师不主张，综合模式标注"供参考"
- **空宫忘借对宫**：遗漏会导致严重误判
- **编造断语**：不确定的如实说，无法追溯的标注"AI推断"
- **讨好倾向**：凶象如实描述，格局不成立就不成格
- **夫妻宫断语遗漏**：武曲/廉贞/七杀/破军在夫妻宫一律建议晚婚
- **婚期只看流年**：须按三层法综合判断
- **格局混淆必须/加分**：必须条件缺一不可，加分条件不是成格必要条件
- **连续化忌年忽视**：需分析累积影响
- **快捷指令未识别**：`\` 开头为快捷指令
- **完成后遗漏提示语**：必须附加文件位置和快捷指令
- **流月缺少流年上下文**：不可孤立分析单月
- **输出写入skills目录**：必须写入 ziwei-output/
