# 事件类型与宫位映射表

## 核心理念

反推时辰第3轮需要用用户的人生事件验证候选时辰。提问必须**具体、深入、多角度**，不能只问"你哪一年结婚了"这种简单问题。要问出事件的**性质、强度、结果**，才能准确匹配盘面信号。

## 事件分类

| 分类 | 事件领域 | 验证强度 | 矛盾触发阈值 |
|------|---------|---------|------------|
| A类 | 感情（夫妻宫）、事业/学业（官禄宫） | 强验证 | ≥2 个矛盾 → 强矛盾标记 |
| B类 | 家庭/父母（父母宫、田宅宫）、健康（疾厄宫） | 中验证 | ≥3 个矛盾 → 强矛盾标记 |
| C类 | 人际/社交（仆役宫、迁移宫） | 辅助参考 | 不触发强矛盾标记 |

## 事件领域与详细提问

### 领域1：感情（夫妻宫+福德宫）—— A类

**详细提问**：

```
先聊感情方面——
1. 你谈过几次恋爱？最近一次是什么时候？
2. 感情中你通常是主动追还是被动等？
3. 分手一般是什么原因？是你主动断的多，还是对方提的多？
4. 有没有哪段感情对你打击特别大？哪一年？具体发生了什么？
5. 你对感情的态度是——
   A. 很看重，觉得必须有
   B. 有最好，没有也行
   C. 麻烦，不太想谈
```

**验证逻辑**：

| 用户回答 | 对应盘面信号 | 验证维度 |
|---------|-----------|---------|
| 主动追 | 夫妻宫有杀破狼、太阳、廉贞等主动星 | 先天行为模式 |
| 被动等 | 夫妻宫有天同、太阴、天相等被动星 | 先天行为模式 |
| 自己主动断 | 夫妻宫化忌+破军/七杀/廉贞，破坏力强 | 事件性质 |
| 对方提的多 | 夫妻宫化忌冲入，自己被动承受 | 事件性质 |
| 打击特别大 | 大限/流年化忌冲夫妻+福德，双重打击 | 事件强度 |
| 很看重 | 身宫在夫妻，或福德宫星曜强旺 | 先天行为模式 |
| 觉得麻烦 | 夫妻宫煞星重，或福德宫化忌 | 先天行为模式 |

**流年验证**：对用户提供的感情事件年份，执行 `--year YYYY` 排盘，检查：
- `yearlyMutagens` 中是否有化禄/化忌/化权触发夫妻宫（`originPalaceName="夫妻"`）
- `decadalMutagens` 中是否有大限四化触发夫妻宫
- 化忌冲夫妻 = 分手/感情危机；化禄入夫妻 = 恋爱/结婚

### 领域2：事业/学业（官禄宫+财帛宫）—— A类

**详细提问**：

```
聊聊事业和学业——
1. 你现在在做什么？上学还是工作了？
2. 学生时代成绩怎么样？有没有偏科？
3. 你更喜欢——
   A. 有明确目标、按部就班地走
   B. 走一步看一步，机会来了就抓住
   C. 经常换方向，很难长期坚持一件事
4. 有没有哪一年事业/学业上有大的变动？升职、换方向、创业、失业？
5. 你对钱的态度——
   A. 很在意，赚钱是第一优先
   B. 够用就行，不刻意追求
   C. 花钱大手大脚，经常存不住
```

**验证逻辑**：

| 用户回答 | 对应盘面信号 | 验证维度 |
|---------|-----------|---------|
| 按部就班 | 官禄宫紫微/天府/天相/太阳 | 先天行为模式 |
| 机会主义 | 官禄宫贪狼/廉贞/破军 | 先天行为模式 |
| 经常换方向 | 官禄宫天机/破军/七杀 | 先天行为模式 |
| 偏科 | 官禄宫文昌文曲+煞星 | 先天行为模式 |
| 大变动年份 | 大限/流年化权/化忌入官禄 | 事件验证 |
| 在意赚钱 | 财帛宫化禄/禄存，或命宫/身宫在财帛 | 先天行为模式 |
| 存不住 | 财帛宫破军/贪狼+化忌，或福德宫耗财 | 先天行为模式 |

**流年验证**：对用户提供的事业变动年份，检查：
- `yearlyMutagens` 中是否有化权/化忌触发官禄宫（`originPalaceName="官禄"`）
- 化权入官禄 = 升职/创业；化忌冲官禄 = 失业/事业受挫

### 领域3：家庭/父母（父母宫+田宅宫+兄弟宫）—— B类

**详细提问**：

```
聊聊家庭——
1. 你跟父母的关系怎么样？小时候呢？
2. 小时候父母管你严不严？是那种很自由的还是管得很紧的？
3. 你有没有兄弟姐妹？关系怎么样？
4. 有没有哪一年家里发生过比较大的变故？搬家、亲人去世、父母离异？
5. 你现在跟父母住一起吗？还是自己住？
```

**验证逻辑**：

| 用户回答 | 对应盘面信号 | 验证维度 |
|---------|-----------|---------|
| 关系不好 | 父母宫化忌+煞星（地劫/陀罗/火星/铃星） | 事件性质 |
| 管得严 | 父母宫紫微/天梁/太阳（权威型） | 先天行为模式 |
| 很自由 | 父母宫天同/贪狼/破军（放养型） | 先天行为模式 |
| 兄弟姐妹少或不亲 | 兄弟宫化忌+煞星 | 事件性质 |
| 家里变故 | 大限/流年化忌冲父母/田宅 | 事件验证 |
| 离家发展 | 迁移宫化禄或强旺 | 先天行为模式 |

**流年验证**：检查 `yearlyMutagens` 中是否有化忌触发父母宫或田宅宫。

### 领域4：健康（疾厄宫）—— B类

**详细提问**：

```
聊聊身体——
1. 你小时候身体怎么样？经常生病吗？
2. 生病一般是哪种？发烧发炎/肠胃问题/呼吸系统/其他？
3. 有没有受过伤？骨折、手术之类的？哪一年？
4. 现在身体怎么样？有没有什么慢性问题？
5. 你对健康的重视程度——
   A. 很在意，有点不舒服就去查
   B. 一般般，扛不住才去医院
   C. 不太在意，能扛就扛
```

**验证逻辑**：

| 用户回答 | 对应盘面信号 | 验证维度 |
|---------|-----------|---------|
| 经常发烧发炎 | 疾厄宫火星/铃星/贪狼/廉贞 | 事件性质 |
| 肠胃问题 | 疾厄宫天府/巨门+煞星 | 事件性质 |
| 呼吸系统 | 疾厄宫天机/太阴+煞星 | 事件性质 |
| 手术/受伤 | 疾厄宫七杀/破军/廉贞+化忌 | 事件验证 |
| 慢性问题 | 疾厄宫化忌+陀罗/地劫 | 事件性质 |
| 很在意健康 | 疾厄宫天梁/天相 | 先天行为模式 |

**流年验证**：检查 `yearlyMutagens` 中是否有化忌触发疾厄宫。

### 领域5：人际/社交（仆役宫+迁移宫）—— C类

**详细提问**：

```
最后聊聊社交——
1. 你的朋友多不多？是那种什么人都认识，还是只有几个铁哥们？
2. 你在外面（学校/公司）的人缘怎么样？
3. 有没有被人坑过？或者跟朋友闹翻过？
4. 你更喜欢——
   A. 一个人待着，自在
   B. 跟朋友一起，热闹
   C. 看情况，有时候想独处有时候想找人
5. 你有没有去过比较远的地方？或者在外地待过很长时间？
```

**验证逻辑**：

| 用户回答 | 对应盘面信号 | 验证维度 |
|---------|-----------|---------|
| 朋友多 | 仆役宫化禄/天同/太阳 | 先天行为模式 |
| 只有几个铁哥们 | 仆役宫天机/太阴/天梁 | 先天行为模式 |
| 被人坑过 | 仆役宫化忌+地劫/陀罗 | 事件验证 |
| 喜欢独处 | 迁移宫弱/命宫强 | 先天行为模式 |
| 喜欢热闹 | 迁移宫太阳/贪狼/廉贞 | 先天行为模式 |
| 去过远方 | 迁移宫化禄/天马 | 事件验证 |

**流年验证**：检查 `yearlyMutagens` 中是否有化忌触发仆役宫，或化禄/天马触发迁移宫。

## 事件验证详细逻辑

### 验证步骤

1. **确定事件年份**：用户给出具体年份
2. **执行流年排盘**：`node scripts/astro.js "YYYY-M-D" hourIndex gender --year YYYY`
3. **定位大限触发**：检查 `yearlyData.decadalMutagens`，找出该大限四化落入的宫位（通过 `originPalaceName`）
4. **定位流年触发**：检查 `yearlyData.yearlyMutagens`，找出该年流年四化落入的宫位
5. **检查宫位触发**：事件相关宫位是否被大限/流年四化触发？
6. **检查四化方向**：四化的方向是否与事件性质一致？
7. **检查事件强度**：事件的严重程度是否与盘面信号强度匹配（多重四化叠加=强事件）？

### 四化方向与事件性质对应

| 事件性质 | 应看到的四化信号 |
|---------|--------------|
| 好事（结婚、升职、发财） | 化禄/化科入相关宫位 |
| 坏事（离婚、失业、疾病） | 化忌冲相关宫位 |
| 变动（搬家、换工作） | 化权入迁移/官禄，或煞星动相关宫位 |
| 开始（恋爱、创业） | 化禄入夫妻/官禄 |
| 结束（分手、倒闭） | 化忌冲夫妻/官禄 |

### 匹配评分规则

| 匹配程度 | 条件 | 得分 |
|---------|------|------|
| 强匹配 | 事件性质+宫位+四化方向完全吻合 | +2 |
| 弱匹配 | 宫位对上但四化不完全吻合 | +1 |
| 矛盾 | 事件与盘面信号明显矛盾 | -2 |
| 无法判断 | 事件太模糊或信号不明确 | 0 |

详细评分和排除规则见 `calibration-protocol.md` 第2.10-2.13节。

## 事件收集策略

### 优先级

1. **先问感情和事业**（A类强验证）：事件最明确，年份好确认
2. **再问家庭和健康**（A类+B类混合）：补充验证
3. **最后问社交**（C类）：辅助参考，不触发强矛盾标记

### 追问技巧

- 用户说"分手了" → 追问"谁提的？什么原因？你当时什么感受？"
- 用户说"升职了" → 追问"是顺理成章的还是有竞争？你当时是开心还是压力大？"
- 用户说"关系不好" → 追问"是从小就不太好，还是某个阶段开始变差的？"

### 避免引导性提问

- ❌ "你是不是2018年结的婚？"
- ✅ "你哪一年结的婚？"
- ❌ "你跟父母关系是不是不太好？"
- ✅ "你跟父母的关系怎么样？"
