# 反推时辰协议

## 目的

通过多轮对话，帮助不知道出生时辰的用户逐步缩小范围，最终确定最可能的出生时辰。

## 核心原则

1. **事件验证是唯一可靠的排除依据**：性格自述、主观感受都不可靠，只有可验证的客观人生事件才能用于排除时辰
2. **性格会变，天命不变**：紫微斗数算的是天命（先天格局），但人的性格表现会随大限流年变化。小时候的性格更接近天命本底
3. **所有候选时辰必须全程参与评分**：不能因为用户"觉得不像"就跳过某个时辰
4. **排盘必须用代码**：所有排盘通过 `scripts/astro.js` 执行，禁止手动推算
5. **结论带置信度**：反推时辰是概率推断，不是确定答案
6. **产出隔离**：反推完成后，用户应使用新的对话去排盘分析
7. **提问要具体**：问具体行为和事件，不问抽象标签

## 反推流程（4轮）

### 第1轮：收集基础信息 + 行为模式问卷

**必须收集**：
- 阳历出生日期（年月日）
- 性别

**可选收集**：
- 大致时间范围
- 出生地点

**候选时辰确定规则**：见 SKILL.md 第1轮。

**行为模式问卷**：5道具体行为问题，请用户回忆小时候（12岁以前）的行为模式。

**问卷评分规则**：仅作为辅助参考分（+1），绝对不能用于排除时辰。

### 第2轮：候选时辰排盘 + 多维度深度对比

**核心步骤**：为每个候选时辰排盘，提取关键差异，生成对比表。

**⚠️ 不排除任何时辰**，只标记倾向。

**性格描述要求**：
- 必须多角度描述，避免单一刻板标签
- 必须区分"天命本底"和"大限影响"
- 必须包含正面和负面两面

**性格描述模板**：

```
【{时辰}】{命宫主星}坐命
- 天命本底（小时候更明显）：
  · 做事风格：{描述}
  · 社交方式：{描述}
  · 情绪特点：{描述}
- 当前大限影响（{当前大限宫位}，{起止年龄}岁）：{描述大限带来的偏移}
- 正面：{描述}
- 容易踩坑：{描述}
```

### 第3轮：深度事件验证（核心步骤）

**这是反推时辰最关键的一轮。**

**事件收集原则**：
1. 分领域逐一询问，不要一次性抛出所有问题
2. 每个领域问得更具体更深入
3. 收集事件的年份、性质、强度、结果
4. 优先收集A类强验证事件

**详细提问模板**：见 `references/event-palace-mapping.md`

**评分规则**：

| 匹配程度 | 得分 | 说明 |
|---------|------|------|
| 强匹配 | +2 | 事件性质+宫位+四化方向完全吻合 |
| 弱匹配 | +1 | 宫位对上但四化不完全吻合 |
| 矛盾 | -2 | 事件与盘面信号明显矛盾 |
| 无法判断 | 0 | 事件太模糊或信号不明确 |

**⚠️ 矛盾权重高于弱匹配**：一个明确的矛盾（-2）比一个模糊的吻合（+1）更有排除力。

**强制规则**：
- 所有候选时辰必须参与事件验证
- 即使用户在第2轮说"某个时辰不像"，该时辰仍需参与第3轮事件评分
- 如果某个时辰事件验证得分反而最高，必须重新纳入

**逐步排除规则**：
- 只有事件验证累计得分持续最低的时辰才能被排除
- 如果两个时辰得分接近（差距≤2），不急于排除，增加验证事件
- 排除时必须说明排除理由

### 第4轮：结论 + 盘外验证

**盘外验证断语要求**：
- 必须是具体的、可验证的
- 必须是用户之前没有提过的领域
- 至少2条，最好3条

**置信度判定**：

| 置信度 | 条件 |
|--------|------|
| 高 | 事件验证得分最高时辰领先≥4分 + 盘外验证≥2条命中 |
| 中 | 事件验证得分最高时辰领先2-3分 + 盘外验证≥1条命中 |
| 低 | 事件验证得分最高时辰领先<2分 或 盘外验证0条命中 |

**盘外验证失败的处理**：
- 0条命中 → 降级置信度
- 0条命中 + 事件得分接近 → 给出2-3个最可能时辰及概率

## 性格随大限变化的处理

紫微斗数算的是天命（先天格局），但人的性格表现会随大限流年变化：

| 阶段 | 大限影响 | 性格表现 |
|------|---------|---------|
| 小时候（第1大限） | 刚起运，影响小 | 最接近天命本底 |
| 青年（第2-3大限） | 大限影响逐渐增强 | 天命+大限叠加 |
| 中年以后 | 大限影响显著 | 可能与天命本底差异大 |

**处理方式**：
1. **问小时候**：12岁以前的行为模式更接近天命本底
2. **标注大限影响**：在性格描述中区分"天命本底"和"当前大限偏移"
3. **不因性格变化排除**：用户说"我现在不是这样的"不代表时辰不对

## 特殊情况

### 跨日时辰

晚上23:00后出生可能涉及早子时/晚子时问题。astro.js 支持 hourIndex=0（早子时）和 hourIndex=12（晚子时）。跨日时需同时排两个子时盘对比。

### 真太阳时

倪师不用真太阳时。默认不使用。

### 完全无线索

用户完全不知道出生时间且无任何线索时：
1. 先排12个时辰的命宫主星对比表
2. 结合行为模式问卷给出辅助参考
3. 进入深度事件验证

### 反推失败

如果4轮对话后仍无法确定时辰：
1. 给出2-3个最可能时辰及其概率
2. 建议用户选择"最可能"的时辰进行排盘
3. 提醒排盘报告中标注"时辰为推断，部分结论需谨慎"
