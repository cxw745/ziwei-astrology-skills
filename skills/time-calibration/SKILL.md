# 紫微斗数反推时辰

## 核心原则

1. **事件验证是唯一可靠的排除依据**：性格自述、主观感受都不可靠，只有可验证的客观人生事件才能用于排除时辰
2. **性格会变，天命不变**：紫微斗数算的是天命（先天格局），但人的性格表现会随大限流年变化。小时候的性格更接近天命本底，成年后受大限影响会偏移
3. **所有候选时辰必须全程参与评分**：不能因为用户"觉得不像"就跳过某个时辰。用户的主观排除是最不可靠的信号
4. **排盘必须用代码**：所有排盘通过 `scripts/astro.js` 执行，禁止手动推算
5. **结论带置信度**：反推时辰是概率推断，不是确定答案
6. **产出隔离**：反推完成后，用户应使用新的对话去排盘分析。反推过程中用户透露的人生经历不应被带入命盘分析
7. **不讨好不编造**：不确定就说不确定，不为了给用户一个"答案"而强行判断
8. **提问要具体，不要抽象**：问"做决定时你更冲动还是深思熟虑"而不是"你是开创型还是保守型"

## 排盘脚本

```bash
node scripts/astro.js "YYYY-M-D" hourIndex gender --json
```

- hourIndex：0=早子时, 1=丑时, ..., 11=亥时, 12=晚子时
- gender："男" 或 "女"
- `--json`：输出完整 iztro 对象的 JSON（反推时辰需要完整数据）

时辰映射见 `references/time-mapping.md`。

## 工作流（4轮）

### 第1轮：收集基础信息 + 时段选择 + 行为模式问卷

> 🔍 **内嵌检查点**：确认必须信息齐全

**必须收集**：
- 阳历出生日期（年月日）
- 性别

**可选收集**：
- 出生地点（用于判断是否跨日）

#### 时段选择（固定步骤）

> ⚠️ 这是缩小候选范围最有效的一步，必须执行。用 AskUserQuestion 工具让用户多选。

**固定输出格式**（必须原样输出以下内容给用户）：

**时段与时辰对应关系**（AI内部使用，不需要再输出给用户）：

| 时段 | 时间范围 | 对应时辰 | hourIndex |
|------|---------|---------|-----------|
| 深夜/凌晨 | 23:00~03:00 | 晚子时(12)、早子时(0)、丑时(1) | 12, 0, 1 |
| 清晨/早上 | 03:00~09:00 | 寅时(2)、卯时(3)、辰时(4) | 2, 3, 4 |
| 上午 | 09:00~11:00 | 巳时(5) | 5 |
| 中午 | 11:00~13:00 | 午时(6) | 6 |
| 下午 | 13:00~17:00 | 未时(7)、申时(8) | 7, 8 |
| 傍晚/晚上 | 17:00~23:00 | 酉时(9)、戌时(10)、亥时(11) | 9, 10, 11 |

**用户选择后的候选时辰确定**：

| 用户选择 | 候选时辰 |
|---------|---------|
| 选了1个时段 | 该时段内所有时辰 |
| 选了2-3个时段 | 合并所有选中时段的时辰 |
| 选了4个以上 | 建议用户缩小范围，如果确实记不清则全量分析 |
| "完全不记得" | 全部13个时辰（早子时~亥时+晚子时） |

**⚠️ 跨时段边界处理**：如果用户选了"中午"但补充说"可能是12点左右"，应同时纳入午时(6)和未时(7)。如果用户选了"深夜/凌晨"但补充说"可能是11点多"，应同时纳入戌时(10)和亥时(11)。

#### 行为模式问卷（同时收集，不单独占一轮）

> ⚠️ 这些问题不是用来排除时辰的，而是为后续事件验证提供辅助参考。人的性格会随大限变化，所以请用户回忆**小时候（12岁以前）**的行为模式，那时候大限刚起运，更接近天命本底。

**固定输出格式**（在时段选择回答后，紧接着输出）：

```
🧠 行为模式（回忆小时候的你）：

1. 做决定时，你更倾向于——
   A. 先做了再说，边做边想
   B. 想清楚再动手，三思而后行

2. 跟一群人在一起时，你通常是——
   A. 主动说话、带动气氛的那个
   B. 先观察，等熟悉了才放开
   C. 看心情，有时候很活跃有时候很安静

3. 遇到不公平的事，你的第一反应是——
   A. 直接怼回去，忍不了
   B. 心里不舒服但先忍着，找机会再说
   C. 看情况，小事算了大事绝不含糊

4. 你对"规矩"和"计划"的态度——
   A. 太多规矩会窒息，喜欢自由发挥
   B. 有计划心里才踏实，不喜欢意外
   C. 大方向要有计划，细节可以灵活

5. 小时候在学校，你更像是——
   A. 领头的那个人，或者自己玩自己的
   B. 跟着大家走，不太出风头
   C. 有一两个好朋友就够了，不太合大群

📌 根据你的选择，候选时辰为：{列出候选时辰名及时间范围}
```

**问卷评分规则**（仅作为辅助参考分，不用于排除）：

| 题目 | 选项A倾向 | 选项B倾向 | 选项C倾向 |
|------|----------|----------|----------|
| 做决定 | 杀破狼系（七杀/破军/贪狼/廉贞/武曲） | 紫微天府系（紫微/天府/天相/太阳） | 机月同梁系（天机/太阴/天同/天梁） |
| 社交 | 杀破狼+太阳 | 太阴+天同+天梁 | 混合型，需结合其他题 |
| 遇不公平 | 七杀/破军/廉贞/武曲 | 天同/天相/天府 | 天机/太阴/天梁 |
| 规矩计划 | 杀破狼系 | 紫微天府系 | 机月同梁系 |
| 学校角色 | 七杀/紫微/破军 | 天同/天府/天相 | 太阴/天机/天梁 |

**⚠️ 问卷评分只作为辅助参考分（+1），绝对不能用于排除时辰。**

### 第2轮：候选时辰排盘 + 多维度深度对比

> 🔍 **内嵌检查点**：排盘必须用代码，所有候选时辰必须排盘

**核心步骤**：

1. 为每个候选时辰排盘
2. 提取多维度差异
3. 生成对比表
4. 结合第1轮问卷给出辅助参考分
5. **不排除任何时辰**，只标记倾向

**排盘命令**（为每个候选时辰执行）：
```bash
node scripts/astro.js "YYYY-M-D" hourIndex gender --json
```

**对比策略**：详见 `references/comparison-strategy.md`

**性格描述要求**：
- 必须多角度描述，避免单一刻板标签
- 必须区分"天命本底"和"大限影响"：说明当前大限可能带来的性格偏移
- 必须包含正面和负面两面

**固定输出格式**（必须原样输出以下结构，表格数据从排盘结果填入）：

```
🕐 反推时辰 — 第2步：候选时辰深度对比

我为你的{候选数量}个候选时辰分别排了盘，关键差异如下：

| 对比维度 | {时辰A}({时间A}) | {时辰B}({时间B}) | {时辰C}({时间C}) |
|---------|----------------|----------------|----------------|
| 命宫主星 | {主星名}(亮度) | {主星名}(亮度) | {主星名}(亮度) |
| 命宫地支 | ... | ... | ... |
| 身宫位置 | {宫名}({主星}) | {宫名}({主星}) | {宫名}({主星}) |
| 化禄落宫 | {星}→{宫名} | {星}→{宫名} | {星}→{宫名} |
| 化忌落宫 | {星}→{宫名} | {星}→{宫名} | {星}→{宫名} |
| 当前大限 | {起止年龄}岁 {宫名} | ... | ... |
| 来因宫 | {宫名} | {宫名} | {宫名} |
| 问卷参考分 | {分数} | {分数} | {分数} |

【{时辰A}】{命宫主星}坐命
- 天命本底（小时候更明显）：
  · 做事风格：{描述}
  · 社交方式：{描述}
  · 情绪特点：{描述}
- 当前大限影响（{当前大限宫位}，{起止年龄}岁）：{描述大限带来的偏移}

- 容易踩坑：{描述}

- 天命本底：
  · 做事风格：{描述}
  · 社交方式：{描述}
  · 情绪特点：{描述}
- 当前大限影响：{描述}
- 正面：{描述}
- 容易踩坑：{描述}

（每个候选时辰都必须有以上完整结构）

👉 接下来我会问你一些具体的人生经历，用客观事件来验证，这才是最靠谱的方法。
```

### 第3轮：深度事件验证（核心步骤）

**这是反推时辰最关键的一轮。所有候选时辰必须参与验证，不跳过任何一个。**

**事件收集**：分领域逐一询问，每个领域问得更具体更深入。

**固定输出格式**（每个事件验证后必须输出）：

```
🕐 反推时辰 — 第3步：事件验证

我需要了解你人生中一些具体的经历，帮我判断哪个时辰的盘面最吻合。
请尽量详细回答，年份、具体情况都说说。

{逐领域提问，见 references/event-palace-mapping.md}
```

**每个事件验证后的固定输出**：

```
📋 事件{N}：{用户描述的事件}

| 时辰 | 相关宫位 | 四化触发 | 匹配度 | 得分 |
|------|---------|---------|--------|------|
| {时辰A}({时间A}) | {宫名}({主星}) | {四化描述} | {强匹配/弱匹配/矛盾/无法判断} | {+2/+1/-2/0} |
| {时辰B}({时间B}) | {宫名}({主星}) | {四化描述} | {强匹配/弱匹配/矛盾/无法判断} | {+2/+1/-2/0} |
| {时辰C}({时间C}) | {宫名}({主星}) | {四化描述} | {强匹配/弱匹配/矛盾/无法判断} | {+2/+1/-2/0} |

📊 当前累计得分：{时辰A}: {总分}, {时辰B}: {总分}, {时辰C}: {总分}
```

**评分规则**：

| 匹配程度 | 得分 | 说明 |
|---------|------|------|
| 强匹配 | +2 | 事件性质+宫位+四化方向完全吻合 |
| 弱匹配 | +1 | 宫位对上但四化不完全吻合 |
| 矛盾 | -2 | 事件与盘面信号明显矛盾 |
| 无法判断 | 0 | 事件太模糊或信号不明确 |

**⚠️ 矛盾的权重提高**：矛盾（-2）比弱匹配（+1）权重大，因为一个明确的矛盾比一个模糊的吻合更有排除力。

**验证必须覆盖所有候选时辰**：即使某个时辰在问卷中"不像"，也必须参与事件评分。如果某个时辰事件验证得分反而最高，必须重新纳入。

**逐步排除规则**：
- 只有事件验证累计得分持续最低的时辰才能被排除
- 排除后仍需说明排除理由
- 如果两个时辰得分接近（差距≤2），不急于排除，增加验证事件

### 第4轮：结论 + 盘外验证

**盘外验证**：从最可能时辰的命盘推导2-3条新断语（未参与校准的预测），请用户确认。

**盘外验证断语要求**：
- 必须是具体的、可验证的，不能是模糊的
- 必须是用户之前没有提过的领域
- 至少2条，最好3条

**固定输出格式**（必须原样输出以下结构）：

```
🕐 反推时辰结论

最可能时辰：{时辰名}（{时间范围}）
置信度：{高/中/低}

📋 验证过程：
- 候选时辰：{列出所有候选时辰及时间范围}
- 事件验证得分：{时辰A}: {分数}分, {时辰B}: {分数}分, {时辰C}: {分数}分
- 排除理由：{简要说明每个被排除时辰的排除原因}

🔍 盘外验证（以下断语未参与校准，请确认是否吻合）：
1. {具体断语1 — 必须是具体的、可验证的、用户之前没提过的领域}
2. {具体断语2}
3. {具体断语3}

👉 以上几条，跟你实际情况吻合吗？

---

📌 确认后，请使用以下信息进行排盘分析：
   {阳历日期} {时辰名} {性别}

⚠️ 重要：请在新的对话中进行排盘，不要在当前对话中继续。反推过程中你提供的人生经历信息不应影响命盘分析的客观性。
```

**置信度判定**：

| 置信度 | 条件 |
|--------|------|
| 高 | 事件验证得分最高时辰领先≥4分 + 盘外验证≥2条命中 |
| 中 | 事件验证得分最高时辰领先2-3分 + 盘外验证≥1条命中 |
| 低 | 事件验证得分最高时辰领先<2分 或 盘外验证0条命中 |

**盘外验证失败的处理**：
- 如果盘外验证0条命中，降级置信度
- 如果盘外验证0条命中且事件验证得分接近，说明可能时辰判断有误，给出2-3个最可能时辰及概率

## 特殊情况

### 跨日时辰

晚上23:00后出生可能涉及早子时/晚子时问题。astro.js 支持 hourIndex=0（早子时）和 hourIndex=12（晚子时）。跨日时需同时排两个子时盘对比。

### 真太阳时

倪师不用真太阳时（"古时一天十二个时辰，万事万物周流变化"）。默认不使用。若用户坚持使用，需告知"可能影响子时判断"。

### 完全无线索

用户完全不知道出生时间且无任何线索时：
1. 先排12个时辰的命宫主星对比表
2. 结合行为模式问卷给出辅助参考
3. 进入深度事件验证

### 反推失败

如果4轮对话后仍无法确定时辰：
1. 给出2-3个最可能时辰及其概率
2. 建议用户选择"最可能"的时辰进行排盘
3. 提醒排盘报告中标注"时辰为推断，部分结论需谨慎"

### 性格随大限变化的处理

紫微斗数算的是天命（先天格局），但人的性格表现会随大限流年变化。处理方式：
- **问小时候**：12岁以前的行为模式更接近天命本底
- **标注大限影响**：在性格描述中区分"天命本底"和"当前大限偏移"
- **不因性格变化排除**：用户说"我现在不是这样的"不代表时辰不对，可能只是大限变了

## ⚠️ 常见陷阱

| 优先级 | 陷阱 | 正确做法 |
|--------|------|---------|
| 🔴高 | 手动排盘 | 必须通过 astro.js 代码执行 |
| 🔴高 | 反推信息带入排盘分析 | 反推完成后必须在新对话中排盘 |
| 🔴高 | 过度承诺时辰准确性 | 结论必须带置信度，低置信度要明确说 |
| 🔴高 | **根据性格自述排除时辰** | **性格描述只能标记"倾向"，不能排除。所有候选时辰必须参与事件验证** |
| 🔴高 | **事件验证不覆盖所有候选** | **即使用户说"不像"，该时辰仍需参与事件评分** |
| 🔴高 | **性格描述太刻板** | **必须多角度描述，区分天命本底和大限影响** |
| 🔴高 | **提问太抽象** | **问具体行为，不问抽象标签** |
| 🟡中 | 事件验证只看四化不看宫位 | 必须同时检查宫位触发和四化方向 |
| 🟡中 | 引导性提问 | "你哪一年结的婚？" 而不是 "你是不是2018年结的婚？" |
| 🟡中 | 忽略性格随大限变化 | 问小时候的行为模式，标注大限影响 |
| 🟢低 | 忽略跨日时辰 | 23:00后需考虑早子时/晚子时 |
